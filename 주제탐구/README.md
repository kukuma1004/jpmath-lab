# 2026 수학 주제탐구 전시

2026-11-02 교사 공개 승인에 따라 22명의 완료 탐구 43개를 `gallery/`에서 공개합니다. 반 이름 대신 미적분Ⅰ 22개·기하 20개·경제수학 1개로 탐색합니다. 작품 목록은 세로로 살펴보고, 개별 탐구는 질문·방법·수행·수정·근거·결론·작품의 가로 7장으로 읽습니다. 원문은 각 장에서 펼칠 수 있습니다. 기존 오리엔테이션·씨앗·교사용 운영 화면은 보존합니다.

## 구성

```text
주제탐구/
├─ gallery/                공개 승인된 통합 전시와 과목별 탐색 데이터
├─ index.html              전체 전시 홈페이지
├─ inquiry.html            학생별 7장 슬라이드형 공통 페이지
├─ exhibition.css
├─ exhibition.js
├─ data/inquiries.json     공개하기로 한 학생 이름과 탐구 데이터
└─ apps/                   검수·공개 승인된 학생 웹앱
```

## 공개 데이터 갱신

1. 별도 로컬 작업 폴더에서 학생 원본을 정리합니다.
2. 성취기준 코드·학생 원문·수학적 정확성·공개 동의를 확인합니다.
3. 공개하기로 한 학생 이름만 남기고 교사 관찰, 평가, 세특 메모를 제거합니다.
4. 검수한 공개본만 `data/inquiries.json`에 반영합니다.
5. 학생 웹앱은 `apps/학생ID/과목/index.html` 경로로 복사하고 JSON의 `studentApp.entry`를 연결합니다.

## 학생별 페이지 방식

- 표지 → 교육과정에서 출발 → 질문 → 탐구 계획 → 학생 웹앱 → 발견 → 연결과 확장의 순서로 한 화면씩 넘깁니다.
- 방향키, 하단 버튼, 마우스 휠, 모바일 좌우 밀기로 슬라이드를 이동합니다.
- 각 장에는 좌표 격자, 함수 그래프, 궤도, 빛, 개념 연결망 등 내용에 맞는 수학 그림을 배경으로 사용합니다.
