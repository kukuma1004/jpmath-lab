# 질문이 남긴 궤적 · 수학 탐구전

2026-11-06 최신 학생 제출 기록을 반영해 25명의 완료 탐구 49개를 전시한다. 미적분Ⅰ 25개·기하 23개·경제수학 1개다. 기존 탐구 7건의 본문을 갱신하고 유석형·장보근·조승인의 탐구 6건을 추가했다. 정지운의 기하는 작성 중이므로 제외한다. 반 이름 대신 과목으로 입장하며, 질문·방법·수행·수정·근거·결론·작품의 가로 7장을 버튼·방향키·좌우 넘김으로 읽는다. 목록과 긴 원문은 세로 읽기를 유지한다.

제출 폴더의 HTML 37편을 학생·과목·내용으로 대조했다. 기존 14편은 보존하고 추가 23편을 연결해 체험 가능한 작품은 총 40편이다. 별도 공개 주소가 있던 4편은 HTML을 기본 체험으로 연결하고 기존 주소도 함께 남겼다. 원본 Sheet와 Drive의 글·파일·권한에는 쓰지 않았다. `refresh-models.js`는 신규 6편의 주제별 수학 모형이며, 학생의 실제 실행 결과와 구분한 전시 해설이다.

- `data/exhibits.json`: 공개 승인된 전시용 기록만 담는다. 학생코드·학생ID·교사피드백·평가·세특·학생 메모·기기 파일 경로는 포함하지 않는다.
- `gallery.js`, `gallery.css`: 과목별 탐색, 학생별 가로 읽기와 밝은 바탕의 읽기 화면
- `exhibition-model.js`: 과목 구분, 단계별 원문 배치, 넘김 범위와 제스처 판정
- `motion-designs.js`: 49개 작품 각각의 주제·관점·7장 장면 문구
- `motion-frames.js`: 단계에 따라 달라지는 전시 해설용 SVG 수학 모형. 단면·투영·광선·접선·경계·오차를 구분한다.
- `living-model.js`, `living-math.js`: 초기 전시의 반투명 재질과 연속 모형을 복원한다. 15개 공간 탐구는 Three.js 입체로, 28개 평면 탐구는 식에서 계산한 Canvas 모형으로 보여 준다. 장을 넘겨도 같은 렌더러와 시간을 유지하며 모형의 조건을 이어 바꾼다. 주제별 관계도는 별도로 선택할 수 있다.
- `motion-story.js`, `motion.css`: 움직이는 모형·단계별 관계도·학생 기록을 이어 읽는 구성. 전체 모형의 등장 회전과 팝업 효과를 줄이고 느린 연결과 선 그리기를 사용한다. 다시 보기·재생/정지·움직임 감소·화면 밖 자동 정리를 지원한다.
- `motion-effects.js`: 수학 좌표를 보존하는 차분한 선·면의 표현. 기본 전시에서는 발광 추적점과 광선 쓸기 효과를 사용하지 않는다.
- `diagram-viewer.js`: 같은 도해를 확대 화면으로 옮겨 1~3배 확대·이동·핀치·장 넘김·재생/정지를 지원한다. 닫을 때 원래 자리와 포커스를 복구한다.
- `scenes.js`, `scenes-inquiries.js`: 전시 해설용 수학 도해. 학생 작품과 구분하여 표시한다.
- `gallery.bundle.js`: 고정된 Anime.js·Three.js 의존성을 포함한 실행본

탐구 완료 상태와 웹앱 제작·수합 상태는 별개다. 교사가 완료를 확인한 기록은 원본 Sheet 상태를 강제로 바꾸지 않고 전시에서만 완료로 반영했다. 웹앱이 없는 기록에는 준비 중 안내를 표시하며, 나중에 해당 작품의 `artifact`만 갱신할 수 있다.

원본 Sheet 전체·비공개 검토 자료·주제 정리가 끝나지 않은 기록은 이 전시에 넣지 않는다. 학생코드와 평가 자료를 제외하고 공개 승인된 전시용 본문만 제공한다. 정적·원문·수식·DOM 모의 검사는 화면·모바일·WebGL·실제 브라우저 동작 검수를 대신하지 않는다.
