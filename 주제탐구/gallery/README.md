# 질문이 남긴 궤적 · 수학 탐구전

2026-11-02 교사가 공개를 요청한 22명의 완료 탐구 43개를 전시한다. 미적분Ⅰ 22개·기하 20개·경제수학 1개다. 반 이름 대신 과목으로 입장하며, 질문·방법·수행·수정·근거·결론·작품의 가로 7장을 버튼·방향키·좌우 넘김으로 읽는다. 목록과 긴 원문은 세로 읽기를 유지한다.

- `data/exhibits.json`: 공개 승인된 전시용 기록만 담는다. 학생코드·학생ID·교사피드백·평가·세특·학생 메모·기기 파일 경로는 포함하지 않는다.
- `gallery.js`, `gallery.css`: 과목별 탐색, 학생별 가로 읽기와 밝은 바탕의 읽기 화면
- `exhibition-model.js`: 과목 구분, 단계별 원문 배치, 넘김 범위와 제스처 판정
- `scenes.js`, `scenes-inquiries.js`: 전시 해설용 수학 도해. 학생 작품과 구분하여 표시한다.
- `gallery.bundle.js`: 고정된 Anime.js·Three.js 의존성을 포함한 실행본

탐구 완료 상태와 웹앱 제작·수합 상태는 별개다. 교사가 완료를 확인한 기록은 원본 Sheet 상태를 강제로 바꾸지 않고 전시에서만 완료로 반영했다. 웹앱이 없는 기록에는 준비 중 안내를 표시하며, 나중에 해당 작품의 `artifact`만 갱신할 수 있다.

원본 Sheet 전체·비공개 검토 자료·주제 정리가 끝나지 않은 기록은 이 전시에 넣지 않는다. 학생코드와 평가 자료를 제외하고 공개 승인된 전시용 본문만 제공한다. 정적·원문·수식·DOM 모의 검사는 화면·모바일·WebGL·실제 브라우저 동작 검수를 대신하지 않는다.
