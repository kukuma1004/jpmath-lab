# 질문이 남긴 궤적 · 수학 탐구전

2026-11-02 교사가 공개를 요청한 22명의 완료 탐구 43개를 전시한다. 미적분Ⅰ 22개·기하 20개·경제수학 1개다. 반 이름 대신 과목으로 입장하며, 질문·방법·수행·수정·근거·결론·작품의 가로 7장을 버튼·방향키·좌우 넘김으로 읽는다. 목록과 긴 원문은 세로 읽기를 유지한다.

- `data/exhibits.json`: 공개 승인된 전시용 기록만 담는다. 학생코드·학생ID·교사피드백·평가·세특·학생 메모·기기 파일 경로는 포함하지 않는다.
- `gallery.js`, `gallery.css`: 과목별 탐색, 학생별 가로 읽기와 밝은 바탕의 읽기 화면
- `exhibition-model.js`: 과목 구분, 단계별 원문 배치, 넘김 범위와 제스처 판정
- `motion-designs.js`: 43개 작품 각각의 주제·관점·7장 장면 문구
- `motion-frames.js`: 단계에 따라 달라지는 전시 해설용 SVG 수학 모형. 단면·투영·광선·접선·경계·오차를 구분한다.
- `motion-story.js`, `motion.css`: 넓은 무대와 학생 기록을 이어 읽는 구성. 선 그리기·단계별 쌓기·좌표 보간과 주제의 선을 따라가는 움직임을 제공한다. 다시 보기·재생/정지·움직임 감소·화면 밖 자동 정리를 지원한다.
- `motion-effects.js`: 수학 좌표를 보존하는 그라데이션·발광과 경로 길이 기준 추적점. 모바일에서는 경로 수를 제한하고 화면 밖과 백그라운드에서는 프레임 실행을 멈춘다.
- `diagram-viewer.js`: 같은 도해를 확대 화면으로 옮겨 1~3배 확대·이동·핀치·장 넘김·재생/정지를 지원한다. 닫을 때 원래 자리와 포커스를 복구한다.
- `scenes.js`, `scenes-inquiries.js`: 전시 해설용 수학 도해. 학생 작품과 구분하여 표시한다.
- `gallery.bundle.js`: 고정된 Anime.js·Three.js 의존성을 포함한 실행본

탐구 완료 상태와 웹앱 제작·수합 상태는 별개다. 교사가 완료를 확인한 기록은 원본 Sheet 상태를 강제로 바꾸지 않고 전시에서만 완료로 반영했다. 웹앱이 없는 기록에는 준비 중 안내를 표시하며, 나중에 해당 작품의 `artifact`만 갱신할 수 있다.

원본 Sheet 전체·비공개 검토 자료·주제 정리가 끝나지 않은 기록은 이 전시에 넣지 않는다. 학생코드와 평가 자료를 제외하고 공개 승인된 전시용 본문만 제공한다. 정적·원문·수식·DOM 모의 검사는 화면·모바일·WebGL·실제 브라우저 동작 검수를 대신하지 않는다.

2026-11-02 모션 개편 후보: 옆에 고정된 도해를 큰 장면 무대로 바꾸고 43개 탐구에 총 301개 장면을 배치했다. 전시 도해의 예시 수치는 학생의 실행·실측 결과로 표시하지 않는다. 학생 원문 430개 필드와 작품 URL은 그대로 보존하며, Sheet·학생 입력·교사 피드백에는 쓰지 않는다. 이 후보의 실제 브라우저·모바일·연출 속도 검수는 미확인이다. 승인된 공개본과 새 로컬 후보를 구분한다.

2026-11-03 모바일 보강 후보: 하단 이전·다음을 본문의 잘림 컨테이너 밖에서 화면에 고정하고 단계 바로 가기를 제공한다. 마지막 장은 다음 탐구로 이어진다. 원문과 수식은 보존하면서 모바일 글자·여백을 조정하고, 도해 크게 보기와 빛·면·경로 추적을 추가한다. 브라우저 접근 제한이 계속되어 실제 모바일·배치·체감 속도는 미검수다. 소프트웨어 검사와 도해 정지 이미지 검토를 실제 화면 검수로 보고하지 않는다.
