이계도함수 탐구실

이계도함수의 부호가 기울기의 변화, 그래프의 굽음, 운동의 가속도와 어떻게 이어지는지 계수와 관찰점을 바꾸며 확인해 보세요.

1. 함수와 관찰점 정하기

기본 함수 세 개 중 하나를 고른 뒤 계수를 직접 바꿀 수 있습니다. 소수도 입력할 수 있습니다.

함수를 선택하면 아래 계수가 자동으로 채워집니다.
위치함수로 보면 1차 미분은 속도, 2차 미분은 가속도입니다.
다항함수의 계수

f(x) = ax⁴ + bx³ + cx² + dx + e에서 각 계수는 −10 이상 10 이하로 입력하세요.

2. 식과 현재 값 확인하기

코드는 입력한 계수를 아래 미분 공식에 대입합니다. 결과를 임의로 정하는 것이 아닙니다.

원함수
f(x) = x³ − 3x

f′(x) = 3x² − 3
이계도함수: 도함수를 한 번 더 미분
f″(x) = 6x

3. 세 그래프 나란히 읽기

각 그래프의 동그란 관찰점을 마우스나 손가락으로 잡아 좌우로 끌어 보세요. 점이 곡선을 따라 움직이고, 세 그래프의 관찰점·점선·슬라이더·계산값이 즉시 함께 바뀝니다. 함수의 모양은 그대로이며, 선택한 위치의 값과 기울기를 비교할 수 있습니다. 각 그래프의 세로축 범위는 따로 조절됩니다.

−3 3
f(0) = 0 f′(0) = −3 f″(0) = 0

그래프의 점을 직접 끌거나 슬라이더·방향키로 0.1씩 조절하세요. 세로값은 선택한 가로값을 함수식에 대입해 정해집니다. 1번 입력과도 연동됩니다.

  • f(x): 원함수
  • f′(x): 기울기
  • f″(x): 기울기의 변화

4. 손계산과 웹앱 비교하기

먼저 ‘손계산 예상’을 직접 계산해 본 뒤 버튼을 누르세요. 웹앱이 계산한 값과 판정이 같은지 비교합니다.

종류 입력 손계산 예상 실행 웹앱 비교 결과
일반값 f(x)=x³−3x, x₀=2 f=2, f′=9, f″=12 아직 실행하지 않음
경계값 f(x)=x³, x₀=0 f=f′=f″=0, f″ 부호 −→+, 변곡점 아직 실행하지 않음
예외값 f(x)=x⁴, x₀=0 f=f′=f″=0, f″ 부호 +→+, 변곡점 아님 아직 실행하지 않음
검증 순서
  1. 종이에 함수값, 도함수값, 이계도함수값을 먼저 계산합니다.
  2. 해당 행의 ‘확인하기’를 눌러 웹앱 결과와 숫자를 비교합니다.
  3. f″(0)=0인 두 사례는 0의 양쪽에서 부호가 바뀌는지도 따로 비교합니다.

이 파일은 입력값을 외부로 보내거나 저장하지 않습니다. 모든 계산은 현재 브라우저 안에서만 이루어집니다.
