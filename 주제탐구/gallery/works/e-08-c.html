미적분Ⅰ: 변화율·누적량을 이용한 실제 데이터 모델 비교

주민등록 인구 월간 CSV를 이용해 선형·지수·로지스틱 모델을 비교합니다. 앱은 최적 모델을 자동으로 결정하지 않습니다.

1. CSV 데이터 입력

아직 CSV가 선택되지 않았습니다.

2. 분석 실행

CSV에서 행정구역과 월별 _총인구수 열을 자동으로 찾아 사용합니다.

3. 실제 인구와 모델 비교

모델별 예측 차이 (모델값 − 실제값)

세 모델의 차이가 작아도 확대해서 비교할 수 있도록 실제값과의 차이를 0을 기준으로 표시합니다.

4. 변화율 분석

실제 데이터의 구간 변화율: (Pi+1 − Pi) / (ti+1 − ti)

미분값 차이 (모델 미분값 − 실제 구간 변화율)

0을 기준으로 차이를 확대해 각 모델의 변화율 차이를 비교합니다.

5. 오차 비교

6. 모델의 수학적 의미

선형

P(t)=at+b
P′(t)=a

일정한 변화율을 가정합니다.

지수

P(t)=Aekt
P′(t)=kAekt

현재 크기에 비례하는 변화율을 가정합니다.

로지스틱

P(t)=K/(1+Ae−kt)
P′(t)=kP(t)(1−P(t)/K)

성장 한계 K에 가까워질수록 변화율이 줄어드는 모델입니다.

7. 직접 검산

첫째·가운데·마지막 시점에서 실제값과 모델 계산값을 비교합니다.
