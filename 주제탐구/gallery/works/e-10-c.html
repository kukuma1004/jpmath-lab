수학적 검증

계산을 먼저, 그래프는 그다음

A · x³, P(1, 0) : 왜 접선은 두 개일까?

H(t) = 2t³ − 3t² = t²(2t − 3). 따라서 t = 0(2중근), 3/2입니다. 접선은 y = 0, y = (27/4)x − 27/4입니다. 서로 다른 접점 2개, 접선 2개입니다.

B · x³, P(1, 0.5) : 세 실근 구하기

H(t) = 2t³ − 3t² + 1/2 = (2t − 1)(t² − t − 1/2). 따라서 t = (1 − √3)/2, 1/2, (1 + √3)/2입니다. 각 t를 y = 3t²x − 2t³에 대입하면 서로 다른 접선 3개를 얻습니다.

C · x⁴, P(0, 1) : 사차인데 왜 0개일까?

H(t) = 3t⁴ + 1은 모든 실수 t에서 양수입니다. 실근이 없으므로 이 점을 지나는 접선도 없습니다. 사차방정식이라는 사실만으로 실근 4개가 존재한다고 말할 수 없습니다.

중복근이 생기면 개수가 반드시 바뀔까?

x³에서는 H′(t) = 6t(t − a)이고 중복근 조건은 b = 0 또는 b = a³입니다. a ≠ 0일 때 b가 0과 a³ 사이이면 접선 3개, 두 경계에서는 2개, 바깥에서는 1개입니다. a = 0이면 항상 1개입니다.

x⁴에서는 H′(t) = 12t²(t − a)입니다. b < a⁴이면 접선 2개, b = a⁴이면 1개, b > a⁴이면 0개입니다. a ≠ 0, b = 0에서 t = 0은 3중근이지만 그 주변의 접선 개수는 2개로 유지됩니다. 중복근 조건은 개수 변화의 후보이지, 항상 변화가 일어나는 충분조건은 아닙니다.

이 결과를 모든 사차함수에 적용해도 될까?

이 도구는 x³과 x⁴만 다룹니다. 두 함수에서는 서로 다른 접점이 서로 다른 접선을 만듭니다. 하지만 f(x) = x⁴ − 2x²는 t = −1, 1에서 동일한 접선 y = −1을 가지므로 일반 사차함수에서는 접점 개수와 접선 개수를 구별해야 합니다.
