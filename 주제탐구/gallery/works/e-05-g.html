5. 수학 원리 확인

① 직선의 방정식

X = A + t·u

A는 직선 위의 기준점, u는 방향벡터입니다. 실수 t를 바꾸면 직선 위의 점을 표현할 수 있습니다.

② 평면의 방정식

n · (X - B) = 0

B는 평면 위의 기준점, n은 법선벡터입니다. 평면 위의 점 X에 대해 B에서 X로 향하는 벡터와 법선벡터의 내적은 0입니다.

③ 벡터의 내적과 외적

a · b = a₁b₁ + a₂b₂ + a₃b₃
a × b = (a₂b₃-a₃b₂, a₃b₁-a₁b₃, a₁b₂-a₂b₁)

내적이 0이면 두 벡터는 수직입니다. 외적이 영벡터이면 두 벡터는 평행합니다. 영벡터는 방향벡터나 법선벡터로 사용할 수 없습니다.

6. 직접 검증하기

아래 예시를 손으로 계산하고 웹앱에 입력하여 결과가 일치하는지 확인하세요.

예시 1. 두 직선의 교차

L₁: (0,0,0) + t(1,0,0)
L₂: (1,-1,0) + s(0,1,0)

t=1, s=1이므로 교점은 (1,0,0)입니다.

예시 2. 두 직선의 꼬인 위치

L₁: (0,0,0) + t(1,0,0)
L₂: (0,1,1) + s(0,1,0)

방향벡터는 평행하지 않고 두 직선의 z좌표가 각각 0과 1이므로 교차하지 않습니다. 꼬인 위치입니다.

예시 3. 직선과 평면의 교차

L: (0,0,0) + t(1,1,1)
평면: (0,0,1), n=(0,0,1)

평면 방정식은 z-1=0입니다. 직선의 z좌표가 t이므로 t=1, 교점은 (1,1,1)입니다.

위 예시는 직접 검증할 수 있도록 구성한 수학적 예시값이며 실험 결과가 아닙니다.
