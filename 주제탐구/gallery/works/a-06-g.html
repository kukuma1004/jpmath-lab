4차원 초구면의 3차원 단면과 정사영 탐구 x² + y² + z² + w² = r²

기하 ‘공간 도형과 좌표’ 확장 탐구 — 좌표 고정(단면) vs 좌표 소거(정사영) 및 차원별 부피 비교

단면 관찰 모드 (w 고정 · 교집합) 초구면 (= 25, 경계 껍질)
x² + y² + z² + (0)² = 25  ⟹  x² + y² + z² = 25
● 반지름 R = 5 인 구면
∅

공집합 (실수해 없음 · 도형이 존재하지 않음)

w = 6 일 때 x² + y² + z² = 25 - 36 = -11 이 됩니다.
실수의 제곱의 합은 음수가 될 수 없으므로 3차원 단면과 만나지 않습니다.

🖱️ 드래그: 3D 회전 • 축 안내: X Y Z

보조 원리 그래프: 제4의 축(w축) 절단면과 3D 구 반지름(R)의 관계

피타고라스 정리 w² + R² = r² 에 의해 고정한 w 위치에서의 세로 절단선 길이가 곧 3차원 구의 반지름 R = √(r² - w²)이 됩니다.

● 왜 단면(좌표 고정)과 정사영(좌표 제거)이 다를까요?

• 단면(교집합): w=k로 고정하면 특정 층의 점들만 남으므로, 속이 빈 초구면을 자르면 속이 빈 구면(x²+y²+z²=25-k²)이 됩니다.
• 3차원 정사영(합집합): w좌표를 없애고 -5 ≤ w ≤ 5의 모든 단면 구면을 3차원 공간에 겹쳐 내려찍으면 속이 꽉 찬 반지름 5인 구(x²+y²+z² ≤ 25)가 됩니다.

심화 완료 기준 충족 자료

반지름(r)과 단위를 고정한 차원별(n차원) 초구의 부피·겉넓이 비교

차원이 높아질 때 부피 증감을 수학적으로 비교하기 위해 동일한 반지름(r)과 단위(cmⁿ)를 고정하여 계산한 결과입니다.

📌 n차원 초구(내부 포함, x₁²+⋯+xₙ² ≤ r²)의 부피 공식
Vₙ(r) = [ π^(n/2) / Γ(n/2 + 1) ] · rⁿ  (단위: cmⁿ)

• 점화식 관계: Vₙ(r) = (2πr² / n) · Vₙ₋₂(r) (단, V₁(r)=2r, V₂(r)=πr²)
• 초구면(경계)의 (n-1)차원 겉넓이: Sₙ₋₁(r) = dVₙ(r)/dr = (n / r) · Vₙ(r)

📚 수학적 출처 및 주의할 점 (완료 기준 반영)

• 공식 출처: 다중적분과 오일러 감마함수(Γ(z))를 이용한 n차원 유클리드 구의 부피 일반화 (참고: Apostol, Calculus Vol.2 / Wikipedia 'Volume of an n-ball').
• 주의점: 반지름이 r = 1로 고정되면 5차원에서 부피가 최대(≈5.26)가 된 후 차원이 커질수록 0에 수렴하고, r = 5로 고정되면 1~10차원에서 계속 증가합니다. 즉 반지름 고정 조건에 따라 증감 양상이 달라집니다.
