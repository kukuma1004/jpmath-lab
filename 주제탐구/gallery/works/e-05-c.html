삼차함수의 비율 불변성 탐구

극댓값 · 극솟값 · 변곡점 · 같은 높이의 다른 교점을 직접 계산하고 그래프로 확인하기

1. 삼차함수 계수 입력

f(x) = ax³ + bx² + cx + d

각 계수는 -100 이상 100 이하의 실수를 입력하세요. a는 0이 될 수 없으며, 극댓값과 극솟값이 모두 존재해야 분석할 수 있습니다.

1.0
범위: -5 ~ 5 (0 제외)
0.0
범위: -10 ~ 10
-3.0
범위: -30 ~ 30
0.0
범위: -10 ~ 10

슬라이더를 좌우로 움직여 보세요. 값이 바뀌는 즉시 함수와 그래프가 다시 계산됩니다. a가 0이거나 두 극점이 존재하지 않는 순간에는 분석 결과 대신 안내가 표시됩니다.

2. 함수 그래프와 주요 지점

함수 그래프 극댓값 극솟값 변곡점 같은 높이의 다른 교점

그래프는 계산된 주요 지점이 화면에 들어오도록 자동으로 범위를 조절합니다. 그림은 관계를 이해하기 위한 시각화이며, 정확한 값은 오른쪽 결과표를 기준으로 확인하세요.

3. 계산 결과

첫 번째 비율—변곡점~극대 / 극대~다른 교점
두 번째 비율—변곡점~극대 / 극대~극소

4. 사용한 수학식과 의미

도함수
f′(x) = 3ax² + 2bx + c
기울기가 0인 지점을 찾아 극댓값과 극솟값의 x좌표를 구합니다.
이계도함수
f″(x) = 6ax + 2b = 0 → 변곡점의 x좌표 x = −b/(3a)
그래프의 오목·볼록이 바뀌는 변곡점의 위치를 구합니다.
변곡점을 기준으로 한 형태
u = x − (−b/(3a)), 그러면 f(x) = au³ + pu + q
좌표를 변곡점만큼 옮기면 이차항이 사라집니다. p와 q는 옮긴 함수에서 계산되는 계수입니다.
극점의 위치
u = ±r, 여기서 r = √(b²−3ac)/(3|a|)
변곡점에서 두 극점까지의 수평 거리는 모두 r입니다.
같은 높이의 다른 교점
극댓값 지점의 변곡점 기준 좌표를 s라고 하면, 다른 교점의 좌표는 u = −2s입니다.
극댓값을 지나는 수평선과 함수 그래프의 다른 교점을 구한 결과입니다.
두 비율
첫 번째 = r/(3r) = 1/3
두 번째 = r/(2r) = 1/2
여기서 거리는 모두 x좌표 사이의 수평 거리입니다. y값 차이나 곡선의 길이를 뜻하지 않습니다.

주의: 이 웹앱은 삼차함수의 수평 방향 거리 비율을 확인합니다. 그래프 위 두 점 사이의 곡선 길이 또는 두 점 사이의 직선거리를 계산하는 도구는 아닙니다.

손계산 검증 방법

  1. 예시 함수에서 f′(x)=0을 풀어 극댓값과 극솟값의 x좌표를 구합니다.
  2. f″(x)=0을 풀어 변곡점의 x좌표를 구합니다.
  3. 극댓값의 y좌표를 함수에 대입해 같은 높이의 다른 교점 x좌표를 구합니다.
  4. 각 x좌표 사이의 절댓값을 계산해 두 비율을 구합니다.
  5. 그 결과를 웹앱의 비율 및 좌표와 비교합니다. 세 예시 모두에서 계산 결과가 일치하는지 확인합니다.

예시 1의 손계산: 변곡점 0, 극댓값 x=−1, 극솟값 x=1, 같은 높이의 다른 교점 x=2입니다. 따라서 첫 비율은 1/3, 두 번째 비율은 1/2입니다.
