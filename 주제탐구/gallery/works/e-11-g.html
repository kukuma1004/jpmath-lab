회전하면 왜 XY항이 생길까?

회전 뒤에는 원래의 x가 X, Y의 혼합식이 된다. 이를 제곱하면 교차항이 생기므로, 일반적으로 이차곡선의 식에 XY항이 나타난다.

1. 내가 바꿀 값

슬라이더나 숫자 칸을 바꾸고 오른쪽 식과 그래프를 확인하세요.

첫 번째 선택이 내가 전개한 식과 같은 관점입니다.
범위: −3 이상 3 이하. a = 0이면 포물선이 아닙니다.
범위: 0° 이상 360° 이하.
범위: −2 이상 2 이하. 원래 점은 P = (t, at²)입니다.
지금은 a = 0이므로 y = 0인 직선입니다. 입력은 계산할 수 있지만 포물선 탐구 조건 a ≠ 0에서는 벗어납니다.

4. 손계산과 비교할 테스트 3개

각 버튼은 좌표축 회전 관점에서 a = 1, t = 1을 넣습니다. 예상 식과 위쪽의 앱 계산식, 예상 점과 P′, 대입 결과를 차례로 비교하세요.

경계값 · 회전 없음

θ = 0°

예상점 P′ = (1, 1), 대입 예상값 = 0

예상 식: X² − Y = 0
일반값 · XY항 발생

θ = 45°

예상점 P′ = (√2, 0), 대입 예상값 = 0

예상 식: ½X² − XY + ½Y² − (√2/2)X − (√2/2)Y = 0
예외값 · XY항 소멸

θ = 90°

예상점 P′ = (1, −1), 대입 예상값 = 0

예상 식: Y² − X = 0
검증 순서: ① 예상 식과 현재 식의 다섯 계수를 비교하고 ② 예상점과 P′를 비교한 뒤 ③ 마지막 대입값이 0 또는 0에 매우 가까운지 확인합니다. 소수 계산에서는 반올림 오차가 생길 수 있습니다.
