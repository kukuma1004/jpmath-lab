포물선 자취 생성기

초점에서의 거리와 준선에서의 거리를 직접 비교하고, p를 바꿔 포물선의 폭을 관찰해 보세요.

1. 조건 바꾸기

0.5 ≤ p ≤ 4, 양수만 허용

−4 ≤ x ≤ 4 · 그래프를 누르거나 드래그해도 점이 움직입니다.

꼭짓점 V(0,0)은 고정됩니다. p를 바꾸면 초점과 준선은 함께 움직입니다.

2. 포물선과 거리 확인

● 포물선 ● 초점 F와 PF ━ 준선과 PD ● 점 P

가로·세로 축은 같은 눈금 크기로 표시하여 폭을 공정하게 비교합니다.

기본 조건
F(0, p), 준선 y = −p
V(0, 0)
두 거리의 의미
PF = √[x² + (y−p)²]
PD = |y+p|

PD는 점 P에서 준선에 내린 수선의 길이입니다.

등거리 조건으로 방정식 유도
PF = PD
x²+(y−p)² = (y+p)²
x² = 4py

그래프의 점은 y = x²/(4p)로 계산합니다.

폭 비교 기준: y = 1
x = ±2√p → 폭 = 4√p

같은 높이에서 좌우 두 점 사이 거리를 비교합니다.

선택한 점 P(x, y)
—
초점까지 거리 PF
—
준선까지 거리 PD
—
