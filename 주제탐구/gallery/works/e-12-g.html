좌표축 회전과 이차곡선의 성질 탐구

회전각을 바꾸면서 이차곡선의 방정식 계수와 교차항이 어떻게 변하는지 확인하고, 회전 전후의 그래프를 비교합니다.

1. 회전각 입력

입력 범위: 0° ~ 360°

현재 회전각: 0°

2. 사용한 수학식

원래 이차곡선은 다음과 같이 설정했습니다.

x² / 9 + y² / 4 = 1

좌표축을 θ만큼 회전시켰다고 생각하고 다음 치환을 사용합니다.

x = u cosθ − v sinθ
y = u sinθ + v cosθ

이 식을 원래 방정식에 대입하면 새로운 좌표 u, v에 대한 방정식이 만들어집니다.

(u cosθ − v sinθ)² / 9 + (u sinθ + v cosθ)² / 4 = 1

특히 uv 교차항의 계수를 확인합니다.

B' = B cos(2θ) − (A − C) sin(2θ)

여기서 원래 식 x²/9 + y²/4 = 1에서는 A = 1/9, B = 0, C = 1/4입니다. 따라서 웹앱에서는 이 값을 이용하여 B'를 계산합니다.

3. 회전 후 방정식의 계수

u²의 계수: 0

uv의 계수: 0

v²의 계수: 0

교차항 계수 B':

B' = 0

4. 그래프 비교

실선: 원래 타원
점선: 회전된 좌표에서 나타난 타원

5. 회전변환에서 무엇이 보존되는가?

거리 → 보존됨

각도 → 보존됨

평행성 → 보존됨

면적 → 보존됨

중점 → 보존됨

곡선의 모양과 크기 → 보존됨

중요한 점은 '방정식의 계수'와 '실제 도형의 기하적 성질'을 구분하는 것입니다. 좌표계를 바꾸면 같은 도형도 다른 식으로 표현될 수 있습니다.

6. 손계산과 웹앱 결과 비교

다음 세 가지 입력을 직접 계산한 뒤 웹앱 결과와 비교해 보세요.

① 경계값: θ = 0°

cos(0°) = 1, sin(0°) = 0을 이용하여 원래 방정식과 같은 결과가 나오는지 확인합니다.

② 일반값: θ = 30°

cos(60°), sin(60°)을 이용해 B'를 직접 계산한 뒤 웹앱의 B'와 비교합니다.

③ 특수값: θ = 45°

2θ = 90°가 되므로 cos(90°), sin(90°)을 이용하여 B'를 직접 계산합니다. 이 값이 실제 웹앱에서 표시되는 값과 같은지 확인합니다.

이 세 결과를 직접 계산해서 일치하는지 확인하는 것이 이 웹앱의 핵심 검증 과정입니다.
