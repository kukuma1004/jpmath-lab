# Google Apps Script 학생 질문함 · 실시간 교사용 운영실

이 폴더의 `Code.gs`, `Index.html`, `Teacher.html`은 비공개 Google Sheet에 연결되는 주제탐구 웹앱 소스입니다. 실제 학생 명단·학생코드·원문 응답은 GitHub에 넣지 않고 Sheet 안에만 보관합니다.

## 이번 구조에서 가능한 일

- 학생은 학생 코드로 이전 작성 내용을 다시 불러와 언제든 수정할 수 있습니다.
- 발문 답변은 세 문항을 다 쓰기 전에도 임시저장할 수 있고, 교사가 다음 단계로 전환하기 전까지 이어서 수정할 수 있습니다.
- 기초응답뿐 아니라 맞춤 발문 답변도 다시 불러와 수정할 수 있습니다.
- 두 탐구의 발문 답변을 모두 최종 제출하면 학생 화면이 자동으로 `탐구·제작` 단계로 전환됩니다.
- 탐구 설계, 실제 수행·제작, 실패·수정, 수학적 해석, 결론·한계·새 질문을 임시저장하며 이어 쓸 수 있습니다.
- 학생별 발문 답변을 다시 활용한 `탐구 코치` 질문이 설계·제작 순서를 안내합니다.
- 웹앱 초보자는 개인정보를 제외한 AI 요청문을 `기획 → 첫 버전 제작 → 오류·개선` 순서로 복사해 사용할 수 있습니다.
- 탐구 기록을 최종 제출하면 학생이 실제로 쓴 내용만으로 `전시 검토` 자료가 만들어지며, 교사 승인 전에는 공개되지 않습니다.
- 학생은 탐구마다 `미적분Ⅰ`, `기하`, `경제수학`, `과목 확인 필요` 중 하나를 선택합니다.
- 선택 과목과 작성 내용이 크게 어긋나거나 학생이 과목을 확정하지 못한 응답은 교사용 화면에서 빨간색으로 표시됩니다.
- 교사는 `승인`, `보완 필요`, `반려`, `검토 대기` 상태와 피드백을 저장할 수 있습니다.
- JP Math Lab 탐구 운영실에서는 승인 여부와 관계없이 학생별 기초응답, 발문 3개, 임시저장·최종제출 답안과 현재 단계를 함께 확인할 수 있습니다.
- 운영실은 진행 단계별 필터와 반 전체 일괄 처리 요청문을 제공하며, 성취기준은 교사 수기 입력 대신 2022 개정 교육과정 대조 작업으로 채웁니다.
- 학생 화면은 12초, 교사용 화면은 8초 간격으로 검토 상태와 새 응답을 다시 확인합니다.
- 학생이 실제 내용을 수정하면 기존 행을 찾아 갱신하고 수정 시각·수정 횟수를 남깁니다. 내용이 같으면 검토 상태를 유지하며, 학생의 처음 제출 시각과 제출ID도 유지됩니다.

## 연결되는 시트

- `학생명단`: 학생 코드, 이름, 현재 진행 단계
- `기초응답`: 2개 탐구의 원문, 과목, 수정 기록, 교사 검토 상태·피드백
- `학생발문`: 학생별 주제, 현재 질문, 맞춤 발문 3개
- `학생답변`: 맞춤 발문 답변, 수정 기록, 교사 검토 상태·피드백
- `탐구과정`: 가설·계획·변인·수행·근거·실패·수정·해석·결론·한계·새 질문
- `전시자료`: 최종 제출된 학생 기록으로 만든 비공개 전시 검토 자료와 승인 상태
- `설정`: 제출 허용 여부

기존 열은 그대로 유지하며 새 기능에 필요한 열만 오른쪽에 추가합니다. `setupInquiryWorkbook`을 실행해도 기존 학생 응답을 덮어쓰지 않습니다.

## 처음 한 번 적용하는 순서

1. Google Sheet에서 `확장 프로그램 → Apps Script`를 엽니다.
2. `Code.gs`와 `Index.html`을 이 폴더의 최신 내용으로 교체합니다.
3. HTML 파일 `Teacher`를 새로 만들고 `Teacher.html` 내용을 붙여 넣습니다.
4. Apps Script 편집기에서 `setupInquiryWorkbook`을 한 번 실행합니다.
5. Sheet를 새로고침한 뒤 `주제탐구 관리 → 현재 운영 상태`로 응답 수와 과목 확인 필요 건수를 확인합니다.
6. `배포 → 배포 관리 → 수정 → 새 버전`으로 기존 웹앱 배포를 갱신합니다.

## 교사용 실시간 페이지 여는 법

Sheet 상단 메뉴에서 `주제탐구 관리 → 실시간 교사용 페이지 열기`를 누릅니다. 표시된 버튼으로 페이지를 열고 북마크해 두면 됩니다.

이 링크에는 서버에서 생성한 긴 교사용 열쇠가 포함됩니다. 열쇠는 Script Properties에만 저장되고 GitHub 소스에는 들어가지 않습니다. 링크를 학생에게 전달하지 마세요. 잘못 공유한 경우 Script Properties의 `TEACHER_DASHBOARD_TOKEN`을 삭제한 뒤 `setupInquiryWorkbook`을 다시 실행하면 새 열쇠가 만들어집니다.

JP Math Lab의 `수업창고 → 탐구 운영실`에서 바로 보려면 Sheet 메뉴의 `주제탐구 관리 → 운영실 실시간 연결 주소`를 누르고 표시된 열쇠를 운영실 연결란에 붙여 넣습니다. 열쇠는 현재 브라우저 탭에만 보관되며, 운영실은 8초마다 승인 전 응답과 작성 중인 발문 답안까지 다시 확인합니다.

## 학생 수정과 교사 되돌려쓰기 흐름

1. 학생이 코드를 입력하면 자신이 작성한 두 탐구와 검토 상태를 불러옵니다.
2. 학생이 기존 탐구의 실제 내용을 바꿔 저장하면 같은 제출ID의 행이 갱신되고 `재검토 대기`가 됩니다. 확인만 하거나 같은 내용을 다시 저장하면 기존 검토 상태를 유지합니다.
3. 교사용 실시간 페이지는 새 응답과 수정 응답을 8초 안팎으로 반영합니다.
4. 교사가 `보완 필요` 또는 `반려`를 선택할 때는 학생이 고칠 수 있도록 피드백을 함께 입력합니다.
5. 학생 화면에도 피드백이 나타나며 학생은 다시 수정해 저장할 수 있습니다.
6. 과목이 애매한 응답은 교사가 올바른 과목을 선택해 승인하거나, 피드백과 함께 다시 작성하도록 돌려보냅니다.
