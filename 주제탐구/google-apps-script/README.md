# Google Apps Script 학생 질문함

이 폴더의 `Code.gs`와 `Index.html`은 비공개 Google Sheet에 연결되는 학생용 질문함 소스입니다.

## 연결되는 시트

- `학생명단`: 학생 코드, 이름, 현재 진행 단계
- `기초응답`: 미적분Ⅰ·기하의 주제선정 원문과 가공 상태
- `학생발문`: 학생 코드, 탐구 주제, 현재 질문, 발문 3개
- `학생답변`: 학생이 제출할 때마다 새 행으로 누적
- `설정`: 제출 허용 여부와 기본 설정

## 현재 수업 흐름

1. 전체 학생이 같은 학생 질문함에서 미적분Ⅰ과 기하의 기초 질문을 각각 작성합니다.
2. 학생 원문은 `기초응답`에 `가공 대기` 상태로 보존합니다.
3. 교사와 Codex가 주제·핵심 질문·성취기준 후보·맞춤 발문을 가공합니다.
4. 교사가 확정한 뒤 `학생명단`의 상태를 `질문정교화`로 바꾸면 학생별 발문 화면이 열립니다.

현재 명단은 기존 12명과 신규 13명을 합한 25명이며, 이전에 받은 12명의 탐구 자료는 삭제하지 않고 참고자료로 보존합니다.

## 배포 원칙

1. Google Sheet의 `확장 프로그램 → Apps Script`에서 바운드 스크립트를 엽니다.
2. 기본 `Code.gs`를 이 폴더의 파일로 교체합니다.
3. HTML 파일 `Index`를 추가하고 `Index.html`의 내용을 붙여 넣습니다.
4. Apps Script 편집기에서 `setupInquiryWorkbook`을 한 번 실행합니다. 기존 자료는 덮어쓰지 않고 시트 이름·열 순서를 점검하며, 없는 시트만 만듭니다.
5. Sheet를 다시 열어 `주제탐구 관리 → 현재 운영 상태`에서 학생 수와 제출 건수를 확인합니다.
6. `배포 → 배포 관리 → 새 버전`을 선택합니다.
7. 실행 사용자는 교사, 접근 사용자는 수업 상황에 맞는 Google 계정 사용자 범위로 설정합니다.

## 교사가 실제로 사용하는 순서

1. `학생명단`에 학생ID, 학생코드, 이름을 입력하고 상태는 `기초응답`으로 둡니다.
2. 학생은 질문함에서 미적분Ⅰ과 기하를 각각 한 번씩 작성합니다.
3. 두 과목을 모두 제출하면 학생 상태가 `기초응답완료`로 바뀝니다.
4. 교사는 `기초응답`의 `가공 대기` 행을 검토하여 주제·핵심 질문·발문 3개를 확정합니다.
5. 확정 내용을 `학생발문`에 넣고 학생명단 상태를 `질문정교화`로 바꾸면 학생 화면이 발문 답변 단계로 전환됩니다.
6. 학생의 후속 답변은 `학생답변`에 새 행으로 계속 누적됩니다.

`setupInquiryWorkbook`은 학생 명단을 자동으로 만들거나 학생코드를 생성하지 않습니다. 실제 명단과 코드는 비공개 Sheet 안에서만 관리합니다.

- 실행 사용자: 교사 계정
