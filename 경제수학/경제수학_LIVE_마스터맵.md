# JP Math Lab 경제수학 LIVE 마스터맵

## 1. 경제수학의 역할

JP Math Lab에서 경제수학은 **전략·친구방·LIVE·다인전**을 담당한다.

학생은 문제의 정답을 고르는 데서 끝나지 않고 다음 과정을 반복한다.

> 경제 상황을 읽는다 → 필요한 수학 도구를 고른다 → 수치를 비교한다 → 전략을 선택한다 → 움직이는 시장 결과를 확인한다 → 다음 전략을 수정한다

핵심 경험은 `누르고 싶다 → 계속 해보고 싶다 → 실제 수학 실력이 좋아진다`이다. 게임의 사건과 숫자는 달라질 수 있지만, 결과를 만드는 경제수학의 관계는 일관되어야 한다.

경제수학 LIVE의 최상위 원칙은 **“수학을 풀게 하지 않는다. 수학을 사용하게 한다.”**이다. 경제 지식만으로도 선택할 수 있지만, 비율·복리·현재가치·환율·대출을 분석할 줄 알면 더 좋은 선택을 할 수 있어야 한다. 별도의 계산 문제를 맞혀야 진행되는 구조와 매 라운드 서술형 근거를 강제하는 구조는 사용하지 않는다.

## 2. 세 가지 학습 층

| 층 | 현재 역할 | 학생 경험 |
|---|---|---|
| 개념 학습 | 15개 교과서 개념 학습실 | 경제 용어를 이해하고 수식·그래프를 직접 조작한다. |
| 혼자 플레이 | 기존 의사결정 게임과 8개 LIVE 게임의 한 기기 모드 | 시간 압박 없이 여러 전략을 시험하고 결과를 수정한다. |
| 친구방 LIVE | 공통 LIVE 엔진과 다인 게임 | 같은 상황에서 서로 다른 선택을 한 뒤 결과와 이유를 함께 비교한다. |

기존 6개 게임은 삭제하거나 LIVE로 억지 변환하지 않는다. 혼자 충분히 생각하고 반복하는 `개인 전략·ARCADE` 층으로 유지한다.

## 3. 공통 LIVE 엔진

모든 LIVE 게임은 다음 흐름을 공유한다.

> 방 만들기 → 닉네임 입장 → 라운드 시작 → 속보와 수치 공개 → 수학 도구 사용(선택) → 1% 단위 의사결정 → 시장 반응 → 결과·순위·수학 관계 공개 → 다음 라운드

### 첫 운영 규격

- 로그인 없이 닉네임 사용
- 6자리 방 코드
- 2~6명
- 모든 LIVE 게임 8라운드, 약 10~15분
- 실시간 캐릭터 이동보다 **턴 기반 동시 선택** 우선
- 게임 종료 후 `한 판 더` 제공
- 슬라이더와 미세조정 버튼은 1% 단위
- 판단 근거 글쓰기는 강제하지 않음
- 사용한 수학 도구는 결과에 행동 기록으로 표시
- 초기에는 무작위 상대 찾기와 채팅을 넣지 않음
- 수업용 닉네임을 권장하고 실명·학번을 수집하지 않음

### 상황 생성 원칙

LIVE는 고정 문제 은행이 아니라 다음 조합으로 상황을 만든다.

> 교육과정 개념 → 수학 모형 → 경제 상황 → 변화 변수 → 학생 선택 → 계산 결과 → 설명

- 사건 자체는 매번 달라질 수 있다.
- 결과는 순수한 확률로 정하지 않는다.
- 금리, 환율, 물가, 수요, 비용, 성장률 같은 관계가 계산 규칙을 만든다.
- 같은 상황과 같은 선택에는 설명 가능한 결과가 나와야 한다.
- 고난도에서는 불필요한 정보와 불확실성을 추가하되 핵심 모형을 숨기지 않는다.

### 수학 도구함

의사결정 화면에는 `% 변화 / 복리 / 현재가치 / 환율 / 대출 월 상환액` 도구를 둔다. 초반에는 기본 도구로 시작하고 라운드가 진행될수록 도구가 열리며, 8라운드에서는 모든 도구를 스스로 골라 쓸 수 있다. 도구 사용 자체에 보너스 점수를 주지는 않는다. 계산 결과를 더 정확하게 해석해 실제 선택이 좋아지는 구조로 만든다.

8라운드의 기본 리듬은 `전략 → 수학 분석 → 전략 → 수학 분석 → 돌발 상황 → 수학 분석 → 전략 → 최종 의사결정`이다. 모든 라운드를 계산 문제로 만들지 않는다.

## 5. 교육과정과 난이도

2022 개정 경제수학의 네 영역을 다음처럼 연결한다.

1. **수와 경제**: 경제지표, 환율, 세금, 단리와 복리, 현재가치, 연금
2. **함수와 경제**: 생산·비용·수요·공급·효용 함수, 균형가격, 부등식의 영역
3. **행렬과 경제**: 여러 지점과 상품의 자료 표현, 행렬 연산, 역행렬 활용
4. **미분과 경제**: 한계량, 탄력성, 최적화

난이도는 계산량만 늘리지 않고 정보 읽기의 수준을 바꾼다.

| 단계 | 제공 정보 | 학생 활동 |
|---|---|---|
| 입문 | 필요한 지표와 관계를 모두 표시 | 계산하고 결과를 확인한다. |
| 기본 | 여러 선택을 비교할 정보를 표시 | 장단점을 비교해 판단한다. |
| 심화 | 불필요한 정보를 함께 표시 | 핵심 변수를 골라 전략을 세운다. |
| 도전 | 일부 전망을 범위나 확률로 표시 | 불확실성을 고려해 위험을 관리한다. |

학습 진행은 `계산 → 비교 → 판단 → 전략 → 사회적 영향`으로 확장한다. 개인 자산 게임에서 시작해 은행·환율·물가를 지나 경제정책 게임으로 연결한다.

## 6. 현재 구현 상태

### 구현됨 (2026-08-24)

- 경제수학 메인을 `개념 학습 / 혼자 플레이 / 친구방 LIVE` 세 입구로 재구성
- 8개 게임의 한 기기 체험판과 Firebase 실시간 친구방
- 참가자 2~6명, 수업용 닉네임
- 모든 게임 8라운드, 방·재경기마다 사건 순서·강도·수치·발문 변화
- 네 가지 대응을 1% 단위로 직접 배분
- 참가자별 비공개 선택과 동시 결과 공개
- 금리·물가·성장률·환율 기반 수익률 계산
- 라운드별 순위, 자산 변화, 수학적 결과 설명
- 같은 참가자로 `한 판 더`
- 게임 상태의 기기 내 임시 저장과 새로고침 복원
- `% 변화·복리·현재가치·환율·대출` 수학 도구함
- 강제 근거 입력 제거, 도구 사용 기록을 결과에 표시
- 라운드 전환·속보·시장 수치·결과·순위 변화 모션
- 라운드 결과를 아이소메트릭 도시로 표시(바닥 넓이=배분, 높이=그 전략의 성과)
- 8라운드 최종 화면의 누적 스카이라인(한 층=한 라운드 기여, 탑 높이=그 전략의 총 기여)
- 혼자 플레이와 친구방이 같은 결과 화면을 사용
- `prefers-reduced-motion` 지원

### 이후 보완

- 교사용 결과 대시보드
- 오래된 방 자동 만료
- 게임별 사건 수와 경제수학 자료의 추가 확장
- 실제 수업 관찰을 통한 라운드 시간과 도구 난이도 조정

## 7. 실제 친구방으로 전환할 때의 데이터 경계

실시간 저장소에는 게임 진행에 꼭 필요한 최소 데이터만 둔다. 수학 도구 사용은 서술형 답안이 아니라 도구 ID 목록으로만 기록한다.

```text
economyRooms/{roomCode}
├─ gameId
├─ status
├─ round
├─ eventOrder[]
├─ hostId
├─ createdAt
├─ players/{playerId}
│  ├─ nickname
│  ├─ ready
│  └─ score
├─ log/{round}/{playerId}          # 최종 스카이라인용 라운드 기록
│  └─ {대응별 비율}                #  성과는 eventOrder 로 다시 계산되므로 배분만 남긴다

economyChoices/{roomCode}/{round}/{playerId}
├─ strategyId: "mix"
├─ allocation: {대응별 비율}
├─ tools: [사용한 도구 ID]
├─ question
└─ submittedAt
```

- 실명, 학번, 이메일은 저장하지 않는다.
- 다른 참가자의 선택은 결과 공개 전까지 읽을 수 없게 한다.
- 오래된 방은 자동 만료시킨다.
- 채팅과 무작위 매칭은 초기 범위에서 제외한다.
- 계산 결과는 클라이언트 표시만 믿지 않고 방장 또는 서버 규칙으로 다시 검증한다.
- `log` 는 방장만 쓸 수 있고 배분 비율(0~100)만 담는다. 서술형 답안은 남기지 않는다.
- 방을 새로 시작하거나 `한 판 더` 를 누르면 `log` 도 함께 비운다.

## 8. 다음 개발 순서

1. 교실과 모바일에서 8개 게임을 실제 플레이하며 라운드 길이와 도구 난이도를 조정한다.
2. 2022 개정 성취기준 원문을 게임별 8라운드 행동과 한 줄씩 역매핑한다.
3. 뉴스 속 수치가 수학 도구의 초기값으로 자연스럽게 이어지도록 사건 데이터를 확장한다.
4. 행렬과 경제·미분과 경제를 직접 사용하는 고난도 사건을 추가한다.
5. 교사용 방 결과 요약과 학생의 도구 사용 흐름을 추가한다. (누적 스카이라인이 그 출발점이다)
6. 오래된 방 만료와 재접속 안정성을 보완한다.

## 9. 완료 기준

새 LIVE 게임은 다음을 모두 만족해야 공개한다.

- 모바일과 전자칠판에서 핵심 정보가 한눈에 보인다.
- 참가자가 입력보다 선택과 조작에 집중한다.
- 글쓰기 없이 바로 결정할 수 있고, 필요할 때 수학 도구를 꺼내 쓸 수 있다.
- 결과가 교육과정의 수학 관계로 설명된다.
- 같은 전략을 반복해도 상황 변화 때문에 판단이 달라진다.
- 승패 뒤에 반드시 `왜 이런 결과가 나왔는가`가 나온다.
- 최종 화면의 탑 높이를 모두 더하면 실제 점수 증감과 정확히 같다. 화면에 찍히는
  소수 첫째 자리 값들의 합도 어긋나지 않는다. 그림이 곧 계산이어야 한다.
- 새로고침·재접속·중복 제출 상황을 처리한다.
- 실명과 학생 개인정보 없이 플레이할 수 있다.
- 움직임 감소 설정과 키보드 사용을 지원한다.
