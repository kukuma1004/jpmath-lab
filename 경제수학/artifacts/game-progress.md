# 경제수학 게임 개선 진행 기록

## 현재 의도와 제약

- 대상: `경제수학/게임.html`의 비아케이드 경제수학 게임 7종과 공통 개념 훈련실
- 학생 약속: 경제 개념을 읽기만 하지 않고, 선택하고 결과를 비교하며 다시 시도한다.
- 시각 방향: JP Math Lab의 밝은 베이지·녹색 계열을 유지한 2.5D 보드게임/디오라마형 화면
- 학습 제약: 변수가 늘어나더라도 계산 관계와 경제 개념의 원인이 숨지 않아야 한다.
- 기술 제약: 기존 정적 HTML/CSS/JS와 GitHub Pages 배포 구조를 유지한다. Firebase나 로그인을 요구하지 않는다.
- 접근성: 전자칠판, 노트북, 태블릿, 모바일에서 핵심 조작과 결과가 읽혀야 한다. `prefers-reduced-motion`을 존중한다.

## 디자인 브리프

- 플레이어 약속: 작은 경제 실험실의 운영자가 되어 매번 다른 조건에서 결정을 내리고 결과의 이유를 설명한다.
- 목표 감정: 정답을 맞히는 긴장보다 “다른 선택이면?”을 다시 시험하고 싶은 호기심.
- 주요 동사: 선택한다, 배분한다, 비교한다, 실행한다.
- 보조 동사: 예측한다, 계산한다, 위험을 조절한다, 다시 시도한다.
- 5~30초 반복: 시장 조건 확인 → 선택/수치 조정 → 예상 결과 확인 → 실행 → 결과와 개념 연결.
- 1~5분 변화: 사건 순서·시장 조건·위험/보상이 달라지고, 누적 점수와 플레이 성향이 형성된다.
- 실패와 학습: 단순 오답 대신 손실·재고·불균형·기회비용의 원인을 한 문장과 수치로 알려 준다.
- 보상: 점수뿐 아니라 장면, 진행 경로, 배지, 누적 그래프와 다음 선택 조건이 바뀐다.
- 숙련자 차이: 단일 최대값보다 여러 목표와 위험을 함께 보고 안정적으로 의사결정한다.
- 비목표: 순발력 중심 아케이드화, 경제 개념과 무관한 복잡성, 저장/로그인 의존.

## 핵심 루프 계약

학생은 **가격·수량·정책·배분을 선택**해 **각 미션의 경제 목표를 달성**한다. 이때 **사건, 수요 변화, 비용과 위험**이 압박을 만들며, 성공하면 **진행·점수·시각 변화와 설명 가능한 결과**를 얻고 실패하면 **어떤 관계를 놓쳤는지 확인한 뒤 즉시 재시도**한다.

## 미션/화면 계획

- 경영 시뮬레이션: 8주 경로, 주간 시장 예보, 가격·생산·전략의 상충, 실행 장면, 주간 리포트.
- 데이터 미스터리: 사건 묶음 랜덤화, 계산 메모, 연속 정답과 근거 피드백.
- 행렬 전략: 지점별 수요/가격 사건, 생산·배송 배분, 폐기 위험과 행렬 계산의 연결.
- 자산 보드게임: 생애 사건 덱, 위험 성향, 저축/수익률/충격의 복리 누적, 자산 도시 성장.
- 시장 균형 RPG: 장소 순서와 조건 변형, 정책 선택 후 수요·공급 장면 변화, 균형 점수.
- 최적화 정원: 첫 퍼즐은 규칙 학습, 둘째는 확인, 셋째는 조건 변형. 한계수확 비교가 조작에 직접 반영된다.
- 경제 전략 카드배틀: 12종 카드, 3개 지역경제 시나리오, 8턴 동안 자본·신뢰·수요·공급·회복력을 함께 관리한다.
- 공통 확장: 30사건 탐정, 업종 3종·난이도 3단계, 무작위 개념 5문제, 12개월 가계 살림, 로그인 없는 결과 카드.

## 최종 상태

- 대표 경영 게임은 빵집 디오라마, 시장 예보, 실시간 예측 KPI, 즉시 조정 컨트롤, 8주 의사결정 장부를 갖춘다.
- 나머지 6종은 서로 다른 장르 화면과 진행 피드백을 유지하면서 공통 베이지·녹색 디자인 언어를 사용한다.
- 카드배틀은 프랜차이즈 요소를 복제하지 않은 독자적 지역경제 정책 덱 게임으로 구성했다.
- 전체 7종의 핵심 입력과 카드배틀 8턴 완주를 자동 검증하고 재시작을 확인했다.
- 8회 새로 진입 검사에서 경영 사건은 6종, 시장 RPG의 첫 등장 인물은 4종이 실제로 달라졌다.
- 데스크톱 1440×1000과 모바일 390×844에서 가로 넘침이 없었다.
- 빵집 장면은 PNG 2,406,447바이트에서 WebP 303,986바이트로 줄였다.
- 검증 시점의 상세 수치는 `final-evidence.md`에 정리했다.
