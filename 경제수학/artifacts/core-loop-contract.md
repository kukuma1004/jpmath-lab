# 경제수학 게임 핵심 루프 계약

## 공통 계약

플레이어는 현재 시장 조건을 읽고 수치 또는 전략을 선택한다. 예상 결과는 입력과 동시에 갱신되며, 실행하면 장면의 움직임과 누적 상태가 바뀐다. 결과 화면은 반드시 `무엇이 바뀌었는가 → 왜 바뀌었는가 → 다음에는 무엇을 바꿀 수 있는가`를 보여 준다.

## 구현 확인 항목

- 입력 후 100ms 안에 예측값·게이지·선택 상태가 반응한다.
- 첫 30초 안에 실제 결과가 달라지는 결정을 할 수 있다.
- 진행률과 이번 목표가 스크롤 위치와 관계없이 읽힌다.
- 성공과 실패가 색만으로 구분되지 않고 아이콘·문장·수치로 함께 표시된다.
- 보상은 점수 외에 다음 상태, 장면, 누적 그래프 또는 배지를 바꾼다.
- 실패 설명은 계산 관계를 노출하고 즉시 다시 시도할 수 있게 한다.
- 새 게임은 사건·순서·수치 조합 중 적어도 하나가 달라진다.
- 모바일 터치 영역은 충분히 크고 화면 밖으로 중요한 조작이 잘리지 않는다.
