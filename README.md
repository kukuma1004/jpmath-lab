# JP Math Lab

## 먼저 읽을 것

**[`JP_MATH_LAB_2.0_MASTER_SPEC.md`](JP_MATH_LAB_2.0_MASTER_SPEC.md) 하나가 현재 기준이다.**
화면을 고치기 전에 이 문서의 §0(권한)과 §10(결정 로그)을 먼저 본다.

**결정이 바뀌면 코드보다 이 문서를 먼저 고친다.**
사람이든 AI든 여럿이 함께 작업하므로, 문서와 코드가 어긋나면 다음 사람이
"명세와 다르다"며 되돌린다. 방향이 계속 틀어지는 원인은 대부분 이것이다.
