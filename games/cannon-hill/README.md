# 와르르 (고개 너머 포싸움)

JP Math Lab의 오리지널 2D 턴제 포격 대전입니다. 바람을 읽고 각도와 힘을 맞춰 고개 너머 상대에게 포탄을 넘깁니다. 땅은 폭발로 파이고, 받침을 잃은 덩어리는 무너지고, 바위는 낙석이 되어 굴러갑니다.

- 공개 경로: `/jpmath-lab/games/cannon-hill/` (표시 이름은 `source/src/game/config/constants.ts`의 `GAME_TITLE` 한 곳에서만 바꿉니다. 폴더 이름과 묶여 있지 않습니다.)
- 모드: AI 대전(쉬움·보통·어려움), 둘이서 하기(한 기기 번갈아). 둘 다 1:1과 2:2를 고를 수 있습니다.
- 2:2: 장수 순서는 `[1팀 첫째, 2팀 첫째, 1팀 둘째, 2팀 둘째]`(편 = 자리 % 2). 편이 번갈아 쏘고 같은 편 안에서는 차례가 돌아가며, 쓰러진 장수는 건너뜁니다. AI 대전에서는 내 편 둘을 내가 번갈아 조종합니다. 같은 편도 폭발과 독무에 다치지만 공(피해량·명중)으로 치지 않습니다. 전체 턴은 고른 수 × 2.
- 두 종류 탄은 첫 차례부터 제한 없이 고릅니다. 기세의 충전·소비가 없고, 고른 탄은 발사 뒤와 다음 자기 차례에도 유지됩니다. 힘 모으기는 비거리를 정하는 기존 조작입니다.
- 기본 체력은 800, 기본 승부 방식은 턴 제한 없는 끝장전입니다. 1:1은 상대 한 명, 2:2는 상대 편 전원이 쓰러지거나 낙사해야 끝납니다. 전장 선택과 설정에서 20·30·40턴 판정전도 선택할 수 있습니다.
- 모든 탄의 기본 발사속도·중력·바람 영향은 같습니다. 유도는 하강 중, 굴착은 지면 접촉 뒤에 발동합니다. 독술사도 같은 각도와 힘으로 같은 장거리에 도달합니다.
- 조준 도움은 기본으로 켜집니다. 내 차례에 현재 탄·바람·위치로 거친 후보를 검사해 상대 방향과 각도 10도·힘 15 폭의 시작 범위만 안내합니다. 자동 조준·자동 발사·힘 보정은 없으며, 이동·탄 변경·다음 차례에 갱신합니다. 힘 게이지에 추천 구간을 표시하고 설정에서 끌 수 있습니다. 계산은 프레임별 예산으로 나눕니다.
- 무작위 대칭 배치: 하늘이 열린 안전한 발판 중 한 쌍을 무작위로 골라, 양 팀을 같은 높이의 거울 위치에 놓습니다. 2:2는 두 쌍을 골라 팀별 높이·간격을 일치시킵니다. 좌우 팀과 아군 순서는 무작위입니다. 충돌 지형의 재질·두께·지지점도 좌우 대칭입니다. 높은 곳에서 떨어질 때 최대 420의 기본 추락 피해를 받고, 낙사 전장에서는 체력과 무관하게 탈락합니다.
- 착탄 후 물리 대기는 최대 약 1.6초의 시뮬레이션 시간 안에 정리하며, 화면에서는 남은 물리만 2.4배로 진행합니다. 다음 조준·힘 모으기는 정상 속도입니다.
- 장수 아홉과 특기(숫자는 `data/characters.ts`의 `TRAIT` 표):
  - 화포장군(대형 화포탄/집중 진천뢰) — 자리 잡은 포격: 1번은 넓은 땅파기, 2번은 좁고 강한 직격. 걷지 않고 쏘면 피해·폭발이 커짐
  - 신궁(관통 화살/삼연시) — 명궁의 눈: 예상 궤적이 길게 보이고 직격 피해가 더 붙음
  - 도깨비(도깨비 폭탄/튕기는 도깨비불) — 도깨비 힘: 맞은 상대를 거의 두 배 멀리 날림
  - 무당(추적 부적탄/삼중 낙뢰) — 신령의 가호: 자기 차례에 자신·가까운 같은 편 회복. 55~125° 고각 부적은 하강 중 420px 안의 적을 추적하고, 낮은 각도는 130px만 보정. 지형에 막히며 같은 편은 추적하지 않음
  - 거북선 장수(철갑 포탄/연속 화포) — 철갑 선체: 잘 밀리지 않고 떨어짐·깔림·낙석 피해 절반
  - 구미호(여우불/분열 여우불) — 사뿐한 여우걸음: 빠른 이동과 낙하 피해 40% 감소
  - 화차장인(삼연 신기전/구룡 화차) — 화약 배합: 암석 파괴 강화. 세 발 집중 연사와 아홉 발 범위 포격
  - 독술사(맹독 항아리/자욱한 독무) — 백독불침: 독 피해 60% 감소. 독무는 장수별 자기 차례 세 번 동안 차례 시작에 48 피해, 구름 밖으로 걸어 나오면 피함
  - 굴착대장(관통 나선탄/지반 붕괴탄) — 튼튼한 안전모: 환경 피해 25% 감소. 1번은 좁은 280px 터널, 2번은 넓은 110px 굴착과 큰 공동. 기반암·구조물 핵은 보존
- 집중 진천뢰는 피해 반경이 좁고, 움직이지 않은 장군의 무방어 상대 직격은 약 588 피해입니다. 넓게 발판을 파는 1번과 역할을 나눴습니다.
- 전장 일곱: 벼랑 외나무다리, 조선 산성, 층층 채석장, 백두산 화산지대, 도깨비 숲, 구름 궁궐, 저승의 강. 다리는 실제로 끊어지는 목재 발판이며 900px 추락선 아래로 떨어지면 탈락합니다. 채석장은 높은 석벽·아래 채굴장·목재 작업대로 고저차를 만듭니다.

## 조작

- PC: `A`/`D` 이동, `←`/`→` 포신 돌리기, `↑`/`↓` 올리기·내리기, `Space` 꾹 눌러 힘 모으고 떼면 발사, `1`/`2` 무기, `Esc` 정지. 둘러보기: 마우스 끌기·`I` `J` `K` `L`, 휠 확대, `Tab` 따라가기/상대/전체, `C` 내 장수로
- 휴대폰: 화면 아래 ◀ ▶ 이동, ▲ ▼ 각도, ⇄ 방향, 큰 발사 단추를 누르고 있다 떼기. 전장을 끌어 둘러보고 두 손가락으로 확대, 오른쪽 위 「보기」(따라가기·상대·전체)·「내 장수로」 단추
- 전투 HUD(`.screen.hud`)는 화면 전체를 덮지만 `pointer-events: none`이라 단추가 아닌 곳의 끌기·확대는 아래 전장(캔버스)으로 갑니다. 이것이 막히면 둘러보기가 통째로 안 되니 e2e의 끌기 시험이 지킵니다.

## 구조

개발 원본은 `source/`, 공개 파일은 이 폴더의 `index.html`과 `assets/`입니다.

- `src/game/combat/battle.ts`: 순수 시뮬레이션(고정 1/60초 걸음, 시드 난수, Phaser 없음). 포탄·폭발·지형 붕괴·낙석·캐릭터 낙하·턴 상태 기계.
- `src/game/terrain/terrain.ts`: 2px 셀 격자. 기반암·구조물만 지지점이고, 폭발한 둘레에서만 연결 요소를 찾아 지지점과 끊긴 덩어리를 떼어 냅니다.
- `src/game/ai/ai.ts`: 실제 포탄 물리(`dryShot`)로 후보를 거르고, 상위 후보는 전투를 통째로 복제해 붕괴·낙사까지 돌려 본 뒤 고릅니다. 프레임마다 시간 예산만큼만 생각합니다.
- `src/game/data/*.ts`: 장수·무기·전장 표. 수치는 여기서만 고칩니다.
- `src/game/render/*`, `effects/*`, `scenes/*`: Phaser 3 화면. 지형은 240px 조각으로 나눠 바뀐 조각만 다시 그립니다. 지형 그림(`terrainPainter.ts`)은 그린 배경과 어울리게 공기와 닿은 가장자리에 굵은 먹선, 공기에서 멀수록 어두운 음영(조각 둘레까지 거리 변환), 큰 색 얼룩, 배경 안개 빛을 섞습니다. 전장별 색은 `data/maps.ts`의 `colors`.
- `src/game/art/*`: 그림. 기존 몸·무기·배경과 호환되는 생성 그림(`source/public/art/`)을 사용합니다. 추가 장수의 회전 무기와 드릴·입자·지형은 코드로 그립니다. 새 다리·채석장 배경과 굴착대장 몸은 PNG이며, 기존 장수 그림은 기존 최적화 WebP를 유지합니다. 그림 파일을 못 불러오면 코드 그림으로 복구합니다.
  - `artAssets.ts`: 장수별 화면 키·앞손 위치(`CHAR_RIG`), 무기별 너비·쥐는 곳(`WEAPON_RIG`). 그림을 바꾸면 이 숫자만 맞추면 됩니다.
  - `artData.ts`: 그림 처리 스크립트가 만든 크기·발 위치(손으로 고치지 않음).
  - 원본과 처리 스크립트는 저장소 밖 `Documents/Claude/2026-11-21/warureu-art`(raw/ 원본, `process.py`: 초록 배경 지우기·자르기·WebP, `prompts.md`: 요청 문구).
  - 고르기 화면·전투 화면 초상은 게임이 몸·무기 그림을 겹쳐 바로 만듭니다.
- `src/game/audio/audio.ts`: 외부 음원 없이 Web Audio로 만든 효과음과 장구 장단 배경음.

## 명령

```powershell
cd games/cannon-hill/source
npm ci
npm test                 # 시뮬레이션 시험(Vitest)
npm run e2e              # 빌드판 브라우저 시험(Playwright, 먼저 npm run build)
npm run bot -- --rounds=2 --diff=normal   # AI끼리 붙여 승률·끼임·턴 정지 확인
npm run build:publish    # 빌드 후 이 폴더로 복사
```

`?qa=1`을 붙이면 시험용 손잡이 `window.__wr`(상태 읽기, 프레임 진행, 직접 발사)가 열립니다. 숨은 미리보기 창은 화면 갱신이 느리니 `__wr.frames(n)`으로 돌려 봅니다.

저장값은 브라우저 localStorage의 `jpml.warureu.` 접두어 아래에만 둡니다.
