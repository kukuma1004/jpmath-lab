# 샷 힘 조정 · 2026-11-26

사용자 피드백 ‘힘이 너무 약하다’에 따라 같은 파워 게이지에서 더 강한 샷을 선택할 수 있도록 초기 충격량 범위를 넓혔다. 실제 초기 속도가 증가하며, 화면 표시만 강해진 것이 아니다.

| 종목 | 이전 최대 속도 | 현재 최대 속도 | 속도 증가 |
|---|---:|---:|---:|
| 3구/4구 |4.5m/s|6.5m/s|약44%|
| 8볼 |7.5m/s|9.5m/s|약27%|

낮은 게이지 비율에서는 여전히 약하게 칠 수 있다. 힘은 게이지에 비례하고 큐의 회전 토크도 같은 충격량에 따라 계산한다. 두 번 눌러 타격하는 조작과 마찰/반발/쿠션 형상은 그대로다. `SHOT_SPEED_LIMITS`와 `shotSpeedLimit(table)`를 실제 샷·AI·예측 Worker가 공유한다. 종목별로 AI만 별도의 힘을 받지 않는다.

## 검증

- `npm test`: **11파일124개 통과**. 기존 충돌/고속 관통/회전·구름/에너지/겹침/포켓·규칙·AI·전체 경기와 새 파워 범위4개 포함. 새 테스트는 최대/낮은 파워 비율, 이전보다 빠른 실제 쿠션 도달, 매 tick 에너지 비증가/유한 상태/안전한 정지를 확인한다.
- 초기 배치부터 물리 샷만으로 진행한 경기: 4구2샷·3쿠션2샷·8볼16샷으로 종료, safetyStops=0. 갱신한 `../bot-matches/` 원자료를 사용한다.
- `npm run build`: TypeScript 검사와 프로덕션 번들 통과. 렌더 구성은 변경하지 않았다.
- [브라우저 파워 검사](browser/result.json): **10개 통과**. 실제 버튼/터치 두 번 누르기로 3종목의 고출력 샷을 실행하고 shot 이벤트의 실제 속도를 검사했다. 관찰한 샷은 4구96%에서6.24m/s, 3쿠션약95%에서6.20m/s, 8볼약99%에서9.37m/s다. 파워 선택은 실시간 입력이므로 정확한 선택값은 JSON을 기준으로 한다.
- 같은 브라우저 검사에서 실제 PredictionWorker의 첫 적분 위치와 동일 입력의 PhysicsEngine 결과가 일치했다. 강해진 샷과 예측선이 다른 속도를 사용하지 않는다.
- [경기 회귀](regression/result.json): **41개 통과**, 페이지/콘솔/HTTP 오류0·서버 쓰기0. 샷·정지/세 종목 승패·재생/AI/콜샷·배치/PC·터치·화면 크기/설정·기록을 재검사했다. 최종 checks/errors 결과가 기준이다.
