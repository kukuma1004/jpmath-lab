# 경기 규칙 구현과 검증 범위

규칙은 렌더 좌표가 아닌 `ShotResult`의 물리 이벤트를 시간·순서 번호로 정렬해서 판단한다. 실제 경기 UI와 AI는 같은 `MatchController`와 개별 규칙을 사용한다. 이 문서는 2026-11-22 코드 검수 기준이다.

## 확인한 원문

- [WPA Rules of Play, effective 2026-10-21](https://wpapool.com/wp-content/uploads/2026/10/WPA-Rules-2026-10-21-211.pdf): 원본 PDF를 `artifacts/references/wpa-2026-10-21.pdf`에 보존했다. 4.3~4.9의 브레이크 선택권, 오픈 테이블·그룹·콜샷·8번 승패·볼 인 핸드를 구현했다. 3.2/3.3의 첫 충돌·후속 쿠션, 3.10/3.11의 헤드 스트링 제한을 함께 적용한다. 불충분한 브레이크의 선택 절차는 일반 파울과 구분한다.
- [UMB 공식 규정 목록](https://www.umb-carom.org/sport/statutes)과 [공식 경기 규정 목록](https://www.umb-carom.org/sport/rules): 3쿠션은 두 번째 서로 다른 목적구에 닿기 전의 수구 쿠션만 센다. 초구의 직접 빨간 공 우선과 후구 초구 재배치를 별도로 다룬다. 후구 허용은 경기별 조건이므로 옵션으로 제공하며 모든 UMB 경기의 단일 조건이라고 표시하지 않는다.
- 4구는 사용자가 요청한 **국내식 사구** 프로필이다. 두 빨간 공 접촉이 1점이며, 상대 수구 접촉은 무시/턴 전환/1점 감점 중 선택한다. 이를 UMB 공식 4구 규칙이라고 부르지 않는다.

## 계약

`MatchController(config)`의 `initialBalls()`는 경기 초구를 만든다. 8볼은 `ballInHand=true`로 시작한다. 초기 수구가 헤드 스트링 위에 표시되더라도, 실제 타격 전 엔진의 유효 배치와 `confirmPlacement()`가 필요하다. `confirmPlacement()`는 배치 대기만 해제하고, 해당 샷이 끝날 때까지 헤드 스트링 제한을 유지한다.

`apply(result)`는 득점·턴·이닝·연속 득점·파울·종료를 갱신한다. `respots`, `openingLayoutFor`, `rerack`은 호출자가 실제 물리 상태에 적용할 명령이다. `pendingChoice` 동안 추가 샷 결과를 반영하지 않으며 `chooseBreak()`는 허용된 선택지만 받는다. 같은 샷 재생에서는 `apply()`를 다시 호출하면 안 된다.

8볼의 일반 스크래치는 상대에게 테이블 전체 볼 인 핸드를 준다. 브레이크의 별도 선택에서는 제한 구역을 유지한다. 공 그룹은 브레이크에서 정해지지 않으며, WPA 프로필은 일반 공도 콜샷을 요구한다. 캐주얼 프로필은 일반 공 콜샷을 끌 수 있지만 8번의 지정 포켓은 유지한다. 브레이크 8번은 즉시 승리로 처리하지 않는다.

## 자동 검증

`npx vitest run tests/rules.test.ts tests/match.test.ts`: **53개 테스트**.

- 4구: 두 빨간 공의 직접 수구 접촉, 반복/간접 충돌 오판 방지, 상대 수구 옵션 3개, 노란 수구, 점수·공격권·최저 0점·목표 종료.
- 3쿠션: 0~2회 미달, 3~4회 성공, 두 번째 목적구 후 쿠션 제외, 반복 목적구/다른 공의 쿠션 제외, 같은 쿠션 반복, 정렬, 초구 빨간 공 직접 우선, 후구의 승리/무승부·초구 재배치.
- 8볼: 그룹·콜샷·세이프티, 합법 동시 충돌, 접촉 후 쿠션과 프로즌 공, 스크래치, 조기/잘못된 포켓/파울 8번, 그룹의 마지막 공과 같은 샷의 8번 실패, 정상 승리, 임시 그룹 선택, 헤드 스트링의 물리 위치 증거.
- 브레이크: 서로 다른 공 4개 쿠션 조건, 브레이크 포켓 후 오픈 유지, 합법/파울 8번 선택권, 스크래치, 불충분 브레이크 수락/직접 재브레이크/상대 재브레이크.
- 전체 경기: 4구 목표 도달과 종료 후 입력 무시, 3쿠션 후구, 브레이크부터 그룹 7개와 8번까지 진행하는 경기, 자유 연습과 재설정.

검수 중 합법 브레이크 8번 재배치 뒤 이닝이 중복 증가하던 문제, 자유 연습 중 8번이 복구되지 않던 문제, 헤드 스트링 목적구 위치를 샷 전 위치로만 검사하던 문제를 고쳤다.

## 남는 물리적 경계

현재 게임은 평면 물리를 사용한다. 점프에 따른 장외 공, 발·의복·큐의 우발 접촉, 고의 비신사 행위, 실제 큐의 밀어내기·이중 타격에 대한 심판 판단은 시뮬레이션하지 않는다. 타격 중복·움직이는 중 타격·잘못된 수구·허용되지 않은 배치는 게임 입력과 물리 계층이 차단한다. 원문 전체의 경기장 심판·장비 규정까지 구현했다는 뜻은 아니다.
