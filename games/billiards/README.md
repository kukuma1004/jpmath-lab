# 3D BILLIARDS

제이피매쓰랩의 3D 웹 당구입니다. **4구 · 3구(3쿠션) · 8볼**을 **AI 대전 / 2인 로컬 대전 / 자유 연습**으로 플레이합니다.

## 플레이

조준한 뒤 샷 버튼이나 **Space를 한 번** 누르면 파워 게이지가 왕복합니다. 원하는 세기에서 **한 번 더** 누르면 타격합니다. 타격 전 Esc 또는 취소 버튼으로 게이지를 취소할 수 있습니다. 미세 조준 ±는 기본 화면에서 바로 사용하고, 당점은 `당점 · 세부`에서 펼칩니다. 미세 조준은 선택한 시점과 확대율을 유지합니다.

- 드래그: 조준. 방향키: 0.5도 미세 조준, Shift+방향키: 0.01도. 탑뷰에서 테이블을 누르면 그 위치를 향해 조준합니다.
- V: 탑뷰/큐 시점. R: 카메라 초기화. 휠/두 손가락: 확대. 우클릭 드래그: 카메라 회전.
- 당점 위/아래: 밀기/끌기. 좌우: 쿠션 반사에 영향을 주는 좌우 회전.
- 움직이는 중에는 새 타격·공 위치·조준 입력을 차단합니다. AI 차례에는 인간의 샷을 차단합니다.
- 8볼 볼 인 핸드: 테이블에서 겹치지 않는 위치를 고르고 확인합니다. 브레이크는 헤드 스트링 뒤에서 시작합니다.
- WPA 8볼: 공과 포켓을 지정합니다. 지정 누락 시 인간 샷은 먼저 선택 안내를 표시합니다. 수비샷을 선언할 수도 있습니다. 탑뷰 포켓을 눌러 지정할 수 있습니다.
- 연습: 배치 선택, 수구 교체, 공 위치 변경과 포켓된 공 복구. 이전 샷 재생과 물리 접촉의 시간 순서 기록.
- 경기 종료: 점수/이닝/샷/연속 득점/파울 기록, 재대결. 최근 12경기는 이 브라우저에 저장합니다.

## 경기 프로필

4구는 **국내식 하우스 규칙**이며 UMB 공식 4구라고 표시하지 않습니다. 두 빨간 공을 맞히면 1점, 정상 득점 시 계속 공격합니다. 상대 수구 접촉은 허용 / 공격권 전환 / 1점 감점 후 전환 중 선택합니다. 3쿠션은 두 번째 목적구 전 수구 쿠션 3회 이상, 초구 빨간 공 직접 우선, 후구 옵션을 분리합니다. 목표 10/20/30점과 사용자 지정을 지원합니다.

8볼은 WPA와 캐주얼을 분리했습니다. WPA는 2026-10-21 발효 규칙 중 게임의 평면 물리로 표현할 수 있는 경기 규칙을 구현했습니다. 오픈 테이블, 그룹 확정, 브레이크, 콜샷, 세이프티, 스크래치·잘못된 첫 접촉·접촉 후 쿠션 미달, 볼 인 핸드, 브레이크 8번·불충분 브레이크 선택과 재배치, 조기/잘못된 포켓의 8번 패배를 처리합니다. 캐주얼은 일반 공 콜샷을 끌 수 있지만 마지막 8번의 지정 포켓은 유지합니다. [규칙 원문과 구현 범위](artifacts/rules-reference.md).

## 실행·개발·검증

저장소 루트에서 정적 서버를 실행합니다.

```powershell
python -m http.server 5192 --bind 127.0.0.1
```

<http://127.0.0.1:5192/games/billiards/>를 엽니다. `file://` 직접 실행은 모듈과 Worker의 브라우저 보안 제한으로 지원하지 않습니다. CDN·로그인·서버 API가 필요하지 않습니다.

`games/billiards/source/`에서:

```powershell
npm ci
npm run dev
npm test
npm run build
npm run test:browser
npm run inspect:canvas
node scripts/performance-check.mjs
```

개발 서버는 5191, 빌드 검수용 저장소 정적 서버는 5192입니다. `test:browser`의 대상은 `BILLIARDS_URL`로 바꿀 수 있습니다. 기본 검수 브라우저는 Windows의 Chrome(D3D11)이며 없으면 설치된 Playwright Chromium을 사용하고 소프트웨어 렌더 여부를 보고합니다. `BILLIARDS_BROWSER`로 채널을 지정할 수 있습니다. FPS는 실제 사용한 renderer 정보를 함께 확인해야 합니다.

빌드는 타입 검사 후 `source/dist/`를 만들고 정적 실행 파일만 상위 게임 폴더로 복사합니다. `build-manifest.json`이 현재 번들을 식별합니다. 이전에 공개한 해시 자산은 `retained-assets.json`에 보존해 캐시된 HTML의 로딩도 유지합니다. 다른 게임·학생 자료·기존 저장은 변경하지 않습니다. 저장 키는 `jpmath-billiards-settings-v1`, `jpmath-billiards-history-v1`입니다.

## 구조

- `src/physics/`: SI 단위, 240Hz 전용 물리, 연속 충돌, 구름/미끄럼/회전, 평면 구면 접촉 충격량, 포켓의 유한 쿠션 면·둥근 끝·기울어진 입구·낙하 경계, 물리 이벤트와 복제.
- `src/rules/`: 종목별 순수 규칙 평가와 MatchController. 9볼 같은 종목은 별도 규칙 모듈과 배치를 추가하는 구조이며 9볼 자체는 포함하지 않습니다.
- `src/game/`: 왕복 파워, 조준→게이지→큐 스트로크→운동→정지→규칙, 재생의 경기 상태 보존, 합성 사운드.
- `src/ai/`: 종목별 후보 생성, 같은 PhysicsEngine의 실제 샷 시뮬레이션, 득점/파울/다음 위치 평가, 4단계 난이도와 Worker. AI와 인간 모두 ShotInput을 사용합니다.
- `src/render/`: 규격을 공유하는 캐롬/포켓 테이블, 번호/회전 표시 공, 큐, 재질, 카메라·공 낙하. 물리 상태는 수정하지 않습니다.
- `src/main.ts`: UI 이벤트·Worker·설정·결과·반응형 입력 연결. QA 훅은 `?qa=1`에서만 설치됩니다.

물리와 샷 속도는 `src/physics/config.ts`, AI 연산량/오차/전략 가중치는 `src/ai/difficulty.ts`에서 조절합니다. 초구와 포켓 랙은 독립 배치 모듈입니다. 리플레이는 샷 직전 상태와 입력을 재현한 후 실제 경기의 공 배치·점수·공격권을 복구합니다.

## 검증 경계

수식/운동량/에너지/고속 충돌·회전·정지, 종목별 규칙·전체 경기, 실제 물리를 사용한 초기 배치부터 종료까지의 AI 경기, 브라우저 조작·터치·화면 크기·재생을 구분해 검증합니다. [최종 증거](artifacts/final-evidence.md), [진행 기록](artifacts/game-progress.md), [물리 모델](artifacts/physics-model.md)을 확인하세요. Phase 1의 이전 캡처는 과거 자료입니다.

**실제 당구대의 고속 촬영 자료에 대한 계수 보정과 오차 측정은 하지 않았습니다.** 일정 계수의 평면 점접촉 모델이며 쿠션 변형/Han·Mathavan 모델, 점프·마세·스쿼트·미스큐·실제 발/의복/큐 접촉의 심판 판정은 포함하지 않습니다. 데스크톱 GPU 측정과 터치 에뮬레이션을 실제 휴대폰 검증으로 간주하지 않습니다.

## 에셋·라이선스

Three.js는 MIT이며 원문을 `THIRD_PARTY_NOTICES.txt`에 보관합니다. 테이블/공/큐/주변·텍스처·효과음은 코드로 생성합니다. 외부 이미지·모델·음원 다운로드와 원격 폰트가 없습니다. 합성 소리는 실제 당구장 녹음이 아니며 AudioManager에서 교체할 수 있습니다. 물리의 기본 원리는 [Kiefl의 billiards physics](https://ekiefl.github.io/2020/04/24/pooltool-theory/)와 [pooltool 문서](https://pooltool.readthedocs.io/en/latest/autoapi/pooltool/physics/index.html)를 참고한 자체 TypeScript 구현입니다.
