# 몽글 대장간 시즌 1 · 무기 랭킹

사용자 요청에 따라 시즌 `season-20261120-1`은 나무검 +0, 별철 10,000개, 효과 하나로 시작합니다. 이전 몽글 대장간 저장과 백업만 초기화합니다. 시즌 저장 키를 분리해 이전 버전의 열린 탭이 새 진행도를 덮어쓰지 못하게 했습니다. 초기화는 한 번이며 이번 시즌의 강화·최고 단계·재료·효과·실패 보정·이력은 재접속 후 유지됩니다.

온라인 무기 기록은 프로젝트 `jpmathlab`의 Realtime Database 중 `mongleForgeV1/season-20261120-1/{anonymousUid}`만 사용합니다. 별도 Firebase 앱 `mongle-forge-ranking-v1`에서 익명 인증하며 기존 학생·교사·다른 게임의 로그인과 연결하지 않습니다. 목록은 상위 100개만 조회합니다. 첫 강화·특수 강화·판매에서 최고 무기를 보관하고 자동 등록하며, 임의 닉네임은 화면에 표시하고 변경·자동 등록 해제를 제공합니다.

공개 필드는 대장장이 닉네임, 무기 이름, 강화 단계, 특수효과 1~3개, 감정가, 서버 등록 시각입니다. 원본 저장·재료·학생 정보는 전송하지 않습니다. 브라우저당 최고 감정가의 무기 한 개를 보관하고, 같은 감정가에서는 기존 무기의 이름을 수정할 수 있습니다. 등록 당시 기록은 원래 무기가 파괴되어도 보관됩니다. 본인만 수정·삭제할 수 있고 조건부 요청으로 동시 등록 충돌을 처리합니다.

감정가는 512자리 0 채움 문자열로 저장하여 JavaScript 정밀도 범위를 넘어도 정렬을 유지합니다. 강화 단계는 128자리 문자열까지 등록합니다. 이 표시 범위를 넘는 무기도 게임에서는 계속 강화할 수 있습니다. 감정가 동점은 Firebase 조회와 동일한 UID 내림차순으로 고정하여 상위 10명을 정합니다. 브라우저 저장을 제출하는 자율 랭킹으로 전체 플레이의 진위는 서버에서 재현하지 않습니다.

## 보호권·판매·생산 보너스

현재 시즌 진행은 `:market-1` 저장 키로 한 번 옮깁니다. 이전 시즌 키의 강화 단계·재료·효과·실패 보정·기록을 유지하면서 오래 열린 탭이 새 보호권·보관 기록을 덮어쓰지 못하게 합니다.

보호권은 도전 단계별 한 장씩 보유할 수 있으며 가격은 `1000 + 목표단계²×100 + 일반 강화비×8` 별철입니다. 성공하면 남겨두고 실패할 때만 사용합니다. 실패 결과를 현재 단계·효과 유지로 전환하며 파괴를 막고 일반 실패 보정을 적용합니다. 판매는 감정가의 10%를 정수 내림하여 지급하고 검과 효과를 제거합니다. 제작비를 내고 새 검을 만들며 보호권과 최고 등록 기록은 보관합니다. 판매 확인에는 무기 세대·단계·효과를 대조하여 다른 탭이 바꾼 검을 잘못 판매하지 않습니다.

기본 제련량은 이전 생산량의 정확히 두 배입니다. 본인 Firebase UID를 확인하고 공용 순위표에서 1~10위에만 초당 `100,95,90,85,80,75,70,65,60,55` 별철을 더합니다. 30초마다 조회하며 검증 유효 기간은 60초입니다. 조회 실패·유효 기간 종료 시 보너스를 중단하고, 새 순위를 과거 미수령 시간에 소급 적용하지 않습니다. 기본 제련의 최대 8시간 오프라인 수령은 유지합니다.

자동 등록할 최고 무기 요약은 파괴·판매 전 상태와 같은 저장 트랜잭션에 보관하고 성공 후 갱신합니다. 연결이 없으면 재접속·온라인 복귀 때 재전송합니다. 공개 기록 삭제는 자동 등록도 끄며 보관 요약을 임의로 다시 게시하지 않습니다. 서버 데이터 형식·보안 규칙은 기존 경로 그대로 사용합니다.

## 특수효과 리롤

효과가 세 개면 특수 강화 버튼이 리롤로 바뀝니다. 세 슬롯 중 하나를 균등 확률로 고르고, 현재 보유한 세 효과를 모두 제외한 나머지 두 후보에서 기존 가중치로 새 효과를 뽑습니다. 따라서 항상 다른 효과 하나만 바뀌며 중복이 생기지 않습니다. 강화 단계·나머지 두 효과·보호권·일반 실패 보정은 유지합니다. 리롤 비용은 세 번째 효과 추가 비용의 두 배이며 교체는 확정입니다. 감정가는 내려갈 수도 있습니다.

리롤 전후 최고 감정가를 자동 등록 보관함에 반영합니다. 낮아진 현재 무기의 판매액은 실제 현재 감정가의 10%이며, 등록된 최고 기록은 유지합니다. 변환 슬롯·교체 전후 효과·감정가는 이력과 저장에 남습니다. 버튼을 누를 때의 무기와 가격 조건을 대조하여 다른 탭이 바꾼 검에 이전 리롤을 적용하지 않습니다.

`ranking.rules.fragment.json`은 부분 규칙입니다. 신선한 운영 규칙을 읽어 `rules.mongleForgeV1`만 추가하고 다른 모든 분기의 해시가 같은지 배포 전·후 비교합니다. 이 파일을 전체 운영 규칙으로 덮어쓰지 않습니다. 공개 조회 상한, 익명 UID 소유권, 닉네임과 무기 이름, 정수 문자열, 효과의 중복·빈 슬롯 순서, 필드 허용 목록과 서버 시각을 검사합니다.

Firebase의 [조회 조건](https://firebase.google.com/docs/database/security/rules-conditions), [조건부 쓰기](https://firebase.google.com/docs/database/rest/save-data#section-conditional-requests), [규칙 REST 배포](https://firebase.google.com/docs/database/rest/app-management)를 따릅니다. Emulator와 운영 검수의 임시 등록 기록 및 익명 계정은 검수 후 삭제합니다.
