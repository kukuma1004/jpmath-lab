## 특수효과 리롤

효과는 잿불(빨강), 노을(주황), 별빛(노랑), 숲(초록), 서리(파랑), 폭풍(남색), 월식(보라)의 7종입니다. 슬롯은 세 개이며 같은 효과를 세 번 붙일 수 있고 배율도 세 번 곱합니다. 추가 효과는 모든 7종에서 가중치로 뽑습니다. 세 개가 모이면 특수 강화 버튼이 리롤로 바뀝니다. 세 슬롯 중 하나를 균등 확률로 고르고 그 슬롯의 이전 효과만 제외한 6종에서 새 효과를 뽑습니다. 다른 두 슬롯과 중복될 수 있습니다. 강화 단계·나머지 두 효과·보호권·일반 실패 보정은 유지합니다. 특수 강화 기본 원가는 `100 + 10×(현재 단계+1)²` 별철이며 두 번째 효과는 기본값, 세 번째는 2배, 리롤은 3배입니다. 최고 기록·과거 생산 업그레이드는 가격에 영향을 주지 않습니다. +32 기준 10,990 / 21,980 / 32,970 별철이며 할인 시간에는 각각 절반입니다. 추가 성공률 60% / 30%는 유지하고 리롤 교체는 확정입니다. 감정가는 내려갈 수도 있습니다.

리롤 전후 최고 감정가를 개인 이력에 반영합니다. 낮아진 현재 무기의 판매액은 실제 현재 감정가의 10%이며, 개인 최고 이력은 보존하지만 공개 랭킹은 리롤 후 현재 값으로 갱신합니다. 변환 슬롯·교체 전후 효과·감정가는 이력과 저장에 남습니다. 버튼을 누를 때의 무기와 가격 조건을 대조하여 다른 탭이 바꾼 검에 이전 리롤을 적용하지 않습니다.

감정가의 기본값은 이전 다항식 `120+15L(L+1)(L+2)`에 `(10+L)/10` 강화 보정을 곱해 내림한 값입니다. 여기에 세 효과의 배율을 곱합니다. 예전 개인 보관 기록도 같은 단계·효과로 재감정하지만 공개 랭킹에는 현재 보유 무기의 감정가만 전송합니다.

## 운영자 단일 무기 수정

`mongleForgeV1/adminGrants/{uid}`는 인증된 본인만 읽고 클라이언트는 쓸 수 없습니다. 운영자가 지정한 시즌·수정 ID·원본 무기 요약·효과 3개·발급 시각을 검증하여 한 번 적용합니다. 이미 파괴·판매한 무기는 살리지 않으며, 발급 후 플레이한 새 무기에는 적용하지 않습니다. 원본과 맞는 기존 보유 무기 및 최고 기록만 반영하고 로컬 저장에 수정 ID를 보관합니다. 운영 변경은 닉네임이 아닌 서버에서 확인한 UID를 대상으로 백업·조건부 갱신·재조회합니다. 이 기능은 사용자 요청에 따른 특정 기록 수정용이며 강화 진위를 서버에서 보증하지 않습니다.

운영자 별철 지급은 같은 소유자 전용 분기의 `credits/{grantId}`에 `{season, amount, issuedAt}`를 추가합니다. 금액은 양의 정수 문자열(최대 18자리)이며 ID별 영수증 `creditReceipts`를 잔액과 한 저장에 기록합니다. 기존 잔액에 더하고 수급 한도로 잘라내지 않습니다. 무기·각인·마법·보호권·최고 기록과 이전 무기 수정은 그대로 둡니다. 현재 저장 키 `:reserve-1`은 `:legends-1`, `:wardrobe-1`, `:credits-1`, `:magic-1`, `:storage-1`과 그 이전 저장을 보존 이전하며, 구버전 탭이 지급 영수증을 삭제해 재지급하는 문제를 격리합니다. 이는 같은 브라우저 저장의 중복 수령 방지이며 서버 지갑이나 여러 기기 간 잔액 동기화 기능은 아닙니다.

## 자동 수급 저장 한도

자동 제련과 순위 보너스의 합계는 최고 강화에 도달했을 때의 기본·최고 기록·현재 강화 생산량을 합한 12시간분까지만 채웁니다. 임시 순위 보너스는 한도 계산에서 제외합니다. +0은 172,800, +32는 69,120,000, +100은 1,655,769,600 별철입니다. 현재 검이 파괴·판매·하락해도 최고 기록 기준 한도는 내려가지 않으며, 최고 기록이 오르면 새 한도를 계산합니다. 할인 시간이나 현재 순위는 한도를 바꾸지 않습니다. 오프라인 수령은 복귀당 최대 8시간이며, 빈 저장고에서 하루 뒤 돌아오면 8시간분을 받고 같은 시각 재조회로 중복 수령하지 않습니다.

온라인·오프라인 수급 모두 남은 공간만 지급하며 한도에 도달한 뒤의 대기 시간은 저장하지 않습니다. 가득 찬 상태에서 사용하면 그 시각부터 수급을 재개합니다. 기존 한도 초과 잔액을 잘라내지 않으며, 감정가 10%의 무기 판매 대금도 전액 지급합니다. 잔액이 한도보다 적어져야 자동 수급이 다시 시작됩니다. 이전 3회분 한도 버전의 열린 탭이 새 잔액을 덮어쓰지 못하도록 저장 키를 `:legends-1`에서 `:reserve-1`로 한 번 옮기되, 강화·효과·보호권·잔액·운영자 수정·지급 영수증을 그대로 보존합니다. 이미 지난 가득 찬 시간을 소급 보상하거나 별철을 새로 시작하지 않습니다.

## 새 버전 자동 갱신과 이전 클라이언트 제한

클라이언트 버전은 엔진의 `clientRevision`, 공개 `release.json`의 `revision`을 같은 증가 정수로 배포합니다. 진입·1분 주기·화면 복귀·온라인 복귀·마지막 확인 이후 15초가 지난 동작 전에 새 버전을 확인합니다. `cache: no-store`와 임의 조회 파라미터를 쓰고, 새 버전 발견 시 새 강화·판매·보호권·특강·등록을 중단한 뒤 진행 중 저장과 Web Lock을 마치고 저장 결과를 확인하여 새 URL로 갱신합니다. 저장이 실패하면 갱신을 멈추고 재시도 버튼을 표시합니다. 동일 갱신을 두 번 시도해도 구버전이면 자동 반복을 멈춰 CDN 전파 중 무한 갱신을 방지합니다. 연결 확인 실패 시 로컬 플레이는 허용하고 재연결 시 다시 확인합니다.

서버 랭킹 생성·갱신은 `rulesVersion: forge-current-1`을 요구합니다. 이전 기록의 조회와 본인 삭제는 유지하며, 같은 점수의 이름 변경에서도 새 클라이언트는 현재 프로토콜을 포함합니다. 순위표 기록과 호환되지 않는 배포에서는 클라이언트의 `rankingProtocol`, 공개 manifest, 서버 허용 값을 함께 변경합니다. 현재 검 순위표를 그대로 쓰는 성공률 완화는 `clientRevision`을 올려 일반 업데이트로 적용합니다. 신규 구현 이전부터 계속 열려 있던 옛 탭은 새 갱신 코드를 실행할 수 없으므로 최초 한 번 새로고침이 필요합니다. 그 탭에서 새 고득점 제출은 서버가 거부합니다. 이 버전 표식은 오래된 정상 클라이언트를 차단하는 장치이며, 결과 조작이나 매크로를 판별하는 서버 강화 판정의 대체물이 아닙니다. 기존 공개 무기나 저장을 지우거나 부정 기록으로 단정하지 않습니다.

## 고유 마법·무기고 확장·목표 자동 강화

기존 7종 각인은 보존합니다. 별도로 화염·빙결·전격·공허·성광의 고유 마법 중 하나가 +100 이상 일반 강화 성공 때 아주 드물게 결속됩니다. 게임 화면에는 추첨 확률을 표시하지 않습니다. 한 무기는 결속 후 속성이 바뀌지 않으며, 리롤·특수 강화·일반 +0 초기화·보호 하락에도 유지합니다. 파괴·판매·새 검 제작 때 현재 무기의 마법은 제거하고 파괴 전 최고 랭킹 기록에는 보관합니다. 마법이 결속된 이후 그 무기가 도달한 최고 단계 `magic.peak`를 따로 보존하여 하락해도 마력이 줄지 않습니다. 제1마력은 +100이며 이후 25단계마다 마력이 증가하고 시각 효과는 5단계까지만 복잡해집니다. 감정가는 기존 각인 감정가에 마법 가치 배율을 곱하며 UI에 추가 보너스를 따로 표시합니다. 모든 속성의 가치 공식은 같고 외형·모션으로 구별합니다.

도감은 184종입니다. 기존 신화 12원형은 +56/+64/+72/+80/+90/+100/+120/+150/+180/+220/+270/+330에서 열립니다. 신화·전설의 무기를 원형으로 독자적인 왕검·언월도·삼지창·망치·봉·쌍날검·차크람·대도·쌍도·대낫·신창을 구성했고, +331 이후에는 +52 이상 고급 원형 45개가 10단계마다 순환하며 각성이 누적됩니다. 원화와 5종 마법 오버레이는 내장 이미지 생성 도구로 만들고 WebP 알파를 보존했습니다. 작업 프롬프트와 드림루프 비교 이미지는 로컬 `.dream-loop/`에 둡니다.

자동 강화는 사용자가 정한 목표까지 기존 일반 강화·보호권 구매만 수행합니다. 기본 설정은 보호권 자동 구매이며, 보호권이 필요하면 구매 비용과 강화 비용을 모두 모은 뒤 시작합니다. 별철 부족 때 기다렸다가 자동으로 재개하고, 목표 도달·사용자 정지·검 파괴 때 멈춥니다. 새 검 제작·판매·특강·리롤은 자동으로 하지 않습니다. 마법 발현은 잠시 감상한 뒤 계속 진행합니다. 한 브라우저의 실행 탭은 Web Lock으로 하나만 유지하며 다른 탭의 정지도 공유합니다. 닫힌 동안 강화는 실행하지 않고 다시 열면 저장한 목표를 이어갑니다. 버전 갱신 중에는 중단하고 저장·갱신을 마친 뒤 목표를 복구합니다. 이미 대기 중인 자동 요청도 정지 후에는 저장 트랜잭션 안에서 취소하여 비용을 쓰지 않습니다.

공개 무기 요약에 `magic`, `magicPeak`를 포함합니다. 마법이 없는 무기는 `none`/`0`으로 표시하며, 검 교체 후 같은 감정가가 되어도 현재 마법 유형·최고 마력 단계를 동기화합니다. 클라이언트 랭킹 프로토콜은 `forge-current-1`을 사용하고 자동 갱신 manifest도 함께 올립니다.

## 보호권 구매와 지연 저장 이벤트

다른 탭의 `storage` 이벤트는 과거 저장 값을 담은 채 늦게 도착할 수 있습니다. 이벤트 본문을 그대로 화면 상태로 적용하지 않고 현재 저장소 값을 다시 읽습니다. 이미 완료된 동작 시각·강화 횟수·무기 세대·보호 발동 횟수·최고 기록·지급 영수증이 뒤로 돌아가는 같은 시즌 저장은 이전 스냅샷으로 처리하고 현재 상태로 복구합니다. 따라서 +99에서 구입한 +100 보호권과 결제 잔액을 과거 자동 저장이 되돌리지 못합니다. 정상적으로 이후 강화에 사용한 보호권은 소비 상태를 받아들이며 부활시키지 않습니다. 저장 직후 읽기 검증도 수행하여 브라우저가 저장을 반영하지 않으면 기존 저장 불가 안내를 표시하고 현재 탭의 진행을 유지합니다.


## 현재 검 랭킹 전환

게임 시즌·지갑 저장 키·별철 지급 영수증·외형·강화 기록은 유지합니다. 공개 랭킹 경로만 `season-20261120-1-current-1`로 분리하여 현재 검을 알 수 없는 과거 최고치를 현재 값으로 오인하지 않게 합니다. 접속한 참여자부터 현재 무기를 게시합니다. 프로필은 `ranking-profile:current-1`에 한 번 옮겨 닉네임·무기 이름·참여 설정과 같은 Firebase 익명 UID를 보존하고, 이전 탭이 새 동기화 상태를 덮어쓰지 못하게 합니다.

현재 랭킹은 값의 증가·감소와 효과·마법 교체를 모두 허용합니다. 소유 UID·프로토콜·필드 형식·서버 시각·상위 100개 조회 제약은 유지합니다. 상위 10명 보너스는 현재 검과 동기화된 현재 보드 순위로만 계산하고, 검이 없거나 참여를 해제하거나 로컬 검과 서버 값이 아직 다르면 중단합니다. 현재 검 등록 버튼은 지속적인 현재 가치 동기화 참여를 켜며, 자동 참여를 끄면 공개 랭킹에서 제외합니다.

## 시련의 문 · 1:1 보스전

강화 +100 권장인 잿불의 파수꾼과 싸웁니다. 전투 시작할 때 현재 보유 검의 강화·선택 외형·각인·고유 마법을 읽습니다. 화면의 공격 버튼 또는 J를 누르면 검이 사거리까지 이동해 한 번 공격합니다. 회피 버튼 또는 Space는 공격 준비를 끊고 근처의 안전한 방향으로 이동합니다. 붉은 예고가 빛나는 동안 회피에 성공하면 다음 공격이 반격으로 강화됩니다.

보스 체력은 240,000이며 65%와 30%에서 다음 페이즈로 넘어갑니다. 휩쓸기, 내려찍기, 돌진, 용암 균열, 산탄, 파동, 연속 강타, 낙하의 범위는 전장에 표시합니다. 화염은 연소, 빙결은 감속, 전격은 연쇄 피해, 공허는 빈틈 공격과 반격 강화, 성광은 타이밍에 맞춘 회피 회복에 반영합니다. 각인은 중복 슬롯 수만큼 고유 효과와 공격력에 반영합니다.

직접 조작 전투의 첫 승리로 파수꾼의 증표 3개를 얻습니다. 증표 1개를 +101~+110 사이의 바로 다음 강화용 수호 보호권 1장으로 교환할 수 있습니다. 수호 보호권을 쓰면 실패할 때 현재 강화와 효과를 유지하며, 별철 보호권과 같이 실패 시에만 소모됩니다. 보호권이 이미 있으면 교환을 막습니다. 무피격 승리는 ‘불길을 걷는 자’ 칭호를, 30초 이내 승리는 ‘황혼의 검륜’ 외형 이펙트를 엽니다. 보상 조건과 현재 획득 상태는 전투 입장 화면에 표시합니다.

현재 저장은 `:guardian-1`이며 최고 처치 시간과 보상을 `duel`에, 수호 보호권 출처를 `guardianProtections`에 저장합니다. `:trial-1`의 진행을 옮길 때, 보유 중인 보호권의 마지막 발급 출처가 이력에 증표 교환으로 남아 있다면 수호 보호권으로 옮깁니다. 출처 기록을 확인할 수 없는 보호권은 기존 보호권으로 이어집니다. 기존 수동 기록은 첫 승리와 30초 기록에 반영하며, 무피격 칭호는 이후 전투에서 받은 피해로 판정합니다. 보호권 교환과 보상 지급은 다른 강화 동작과 같은 Web Lock과 저장 트랜잭션을 씁니다.

전투 중 열린 탭의 자동 강화와 주기 저장·대장간 화면 갱신을 쉬고, 창을 닫으면 저장한 목표를 이어갑니다. 별철 수급은 경과 시간을 다음 저장에서 계산합니다. 전투 바닥의 경고 범위는 패턴이나 장판이 달라질 때만 다시 그리며, 입력과 판정은 화면 효과의 그리기 주기와 독립적입니다. 숨긴 화면에서는 전투가 일시정지되고 계속하기를 누르면 재개합니다. 버전 갱신은 전투창을 닫고 기존 저장을 검증한 뒤 적용합니다.
