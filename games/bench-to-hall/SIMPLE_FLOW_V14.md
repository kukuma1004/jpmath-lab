# R14 시즌 흐름 간소화

2026-11-03 R14 변경 내용입니다. 사용자가 배포를 승인했으며, 공개 반영은 Pages 완료 상태·파일 해시·격리 브라우저로 별도 검증합니다.

[킥루](https://kickru.com/)에서 가상 고교 선수의 첫 시즌을 진행해, 진행 화면의 상태 문구·진행 바·건너뛰기와 비시즌의 확인할 일 중심 구성을 직접 확인했습니다. 야구 게임도 진행·요약·선택에 집중하도록 표시 순서를 바꿨습니다.

- 시즌 진행: 큰 구장·선수 애니메이션, 하단 메뉴, 잔액, 여섯 월 표시를 진행 중에 숨깁니다. 현재 상황·핵심 중계 한 줄·진행 바·건너뛰기만 남겼습니다. 야구공과 진행 바에 작은 움직임을 주고 줄어든 모션 설정도 유지합니다. 36초 진행 시간과 저장된 시즌 결과는 그대로입니다.
- 시즌 결과: OVR 변화와 타자/투수/투타겸업의 핵심 성적 네 개를 첫 화면에 보입니다. 상세 성적·성장·순간·반응·가을야구는 '자세히 보기'에서 엽니다. 다음 행동은 '겨울 준비하기' 하나입니다.
- 비시즌: 전환점 효과를 선택지에 바로 표시합니다. 상점은 잔액 옆에서 바로 열고, 훈련·이적·관리는 접힌 준비 메뉴로 모았습니다. 준비 화면에는 선택 화면으로 돌아가는 버튼을 두고, 실제 다음 시즌 진행은 메인 선택 화면에서 합니다.
- 대표팀 참가 알림과 팔꿈치 치료 요구는 메인 선택 화면에 계속 표시합니다. 기존 진행 가드, 병역·계약·성장·상점의 행동 함수와 규칙은 그대로입니다. 상점의 여러 상품 비교·무작위 추억도 유지하며, 상점 안에서는 잔액이 보이게 했습니다.
- 저장 스키마·게임 엔진은 변경하지 않았습니다. 기존 저장은 그대로 읽습니다.

검수는 자동 순위가 꺼진 별도 로컬 저장 공간과 가상 선수로 진행했습니다. 새 선수 생성, 두 시즌의 진행/건너뛰기, 결과, 성장 기록 열기, 전환점 선택·다음 시즌, 프로 저장 가져오기, 상점 비교, 준비 메뉴·계약 화면 접근을 확인했습니다. 실제 기기 검수나 운영 저장 변경은 하지 않았습니다. 로컬 자료는 `.dream-loop/flow-v14/`에 있습니다.
