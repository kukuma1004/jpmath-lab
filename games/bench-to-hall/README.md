## v4 검수본 · 포지션 / 자동 은퇴 / 성장 / 사복 엔딩

사용자가 2026-10-24 Dream Loop 점검 후 이번 v4 전체의 운영 배포를 승인했습니다. 아래는 이번 릴리스에 포함된 변경입니다.

- 포수·내야 4위치·외야 3위치, 지명타자(DH), 선발·불펜·마무리를 생성 2단계에서 선택합니다. 포지션별 중요 능력 가중치, 주전 기회, 수비 기록과 피로를 다르게 계산합니다. DH는 수비 기록이 없습니다. 불펜은 짧은 이닝·홀드, 마무리는 세이브, 선발은 체력에 따른 긴 이닝을 남깁니다.
- 비시즌 훈련 → 포지션에서 다음 시즌 전향을 예약합니다. 전향 적응도는 60 → 80 → 100으로 두 출전 시즌에 걸쳐 회복합니다. 기존 선수의 첫 포지션 지정은 100부터 시작하며 과거 수비 위치·OVR·기록을 만들어 넣거나 다시 계산하지 않습니다.
- 은퇴는 게임이 결정합니다. 투수는 35세, 타자·투타는 37세부터 기량·나이·최근 출전·건강을 평가해 고별 시즌을 예고합니다. 다음 출전 시즌이 끝나면 자동 확정하고 최장 45세 시즌에 마무리합니다. 재활·현역 복무 공백과 그 직후에는 일반 조기 은퇴 판정을 피하고, 예정된 고별 경기는 실제 출전까지 미룹니다. 최대 연령은 별도 상한입니다. 중도 마무리는 저장 메뉴에 남깁니다.
- OVR 82 고정 제한은 없습니다. 잠재력에 가까워질 때 지나치게 줄던 자연 성장을 완화하고 선수/훈련 화면에 잠재력 등급·성장 목표·우선 훈련 능력을 표시합니다. 프로 OVR 72 이상, 투수 32세/타자·투타 35세까지 기술 재정립을 예약할 수 있습니다. 성공 최대 2회, 성공 시 잠재력 +3와 한 출전 시즌 전 능력 성장 +0.8, 적응 중에도 +0.2. 성공은 보장하지 않으며 재도전은 지난 도전 뒤 2시즌부터입니다.
- KBO 4등록 시즌 뒤 이적 탭이 해외 진출을 바로 보여 줍니다. NPB 1군 경쟁 기본 기준은 OVR 75, MLB는 81이며 미달해도 2군·마이너 제안이 나옵니다. 구단 탭은 비교용이고 합의는 별도로 합니다. 해외 제안을 보는 동안 하단 기본 행동도 제안 검토로 바뀌어, 합의 없이 다음 시즌으로 넘기는 혼동을 줄였습니다.
- 모바일 홈을 줄이고 스타일 후보·시즌 결과·비시즌·선수 화면을 탭 한 장씩 처리합니다. 비시즌은 전환점/훈련/이적/관리, 관리 안에는 건강/상점/대표팀/병역이 있습니다. 선택은 탭 전환·재접속에도 유지합니다.
- 24명 × 6가지 사복·모델 원화 144장을 얼굴별로 사전 생성했습니다. 해설위원 수트, 지도자 폴로, 사업가 니트·블레이저, 여행 트렌치코트로 두 번째 삶을 고릅니다. 20세 이상 은퇴 선수는 패션 모델·스포츠 모델도 고를 수 있습니다. 얼굴별 성인 은퇴 원화를 참조해 오프숄더·민소매·오픈 셔츠·스포츠웨어 화보를 미리 만들었습니다. 진로 선택은 성적·전당 점수와 무관합니다. 실시간 이미지 API·가입·대기·생성 비용이 없습니다. 그림은 선택할 때 해당 WebP 하나만 불러옵니다. 현재 은퇴북 5페이지와 기존 얼굴 카드도 유지하고 사복 포스터는 1080×1920 PNG로 저장합니다.

포지션 설명은 MLB 공식 [포수](https://www.mlb.com/glossary/positions/catcher), [유격수](https://www.mlb.com/glossary/positions/shortstop), [중견수](https://www.mlb.com/glossary/positions/center-fielder), [구원투수](https://www.mlb.com/glossary/positions/relief-pitcher), [DH](https://www.mlb.com/glossary/positions/designated-hitter)를 참고했습니다. 역할 차이를 게임으로 단순화한 것이며 수치·은퇴 나이·계약 기준은 공식 리그 규정이 아닙니다. 원화·프롬프트·카탈로그는 `assets/afterlife/`를 참고하세요.

## 플레이와 저장

캐릭터 생성 → 시즌 보내기 → 결과 확인 → 비시즌 선택을 반복합니다. 투수·타자·투타겸업, 24종 아바타, 고교·대학·KBO·NPB·MLB 기본 경로, 성장 이벤트 31개, 5페이지 은퇴 요약과 PNG 카드, 로컬 명예의 전당을 지원합니다.

회원가입과 광고는 없습니다. 전체 선수 기록은 기기와 브라우저에 저장하며 온라인 등록을 선택한 요약만 서버에 공개합니다. 다른 주소·브라우저·기기로 옮길 때 설정에서 JSON을 내보내고 가져오세요. `JP Math Lab · 게임으로`를 누르면 저장을 확인한 뒤 게임 목록으로 돌아갑니다. 기존 v1/v2/v3 파일과 진행 중인 시즌·비시즌·전당은 같은 로컬 저장 키로 읽습니다. 포지션·성장 돌파·자동 은퇴·두 번째 삶 등 새 필드가 포함된 저장은 v4로 내보냅니다. 새 필드가 없는 이전 저장은 v2/v3 구조를 유지하며 기존 난수·자금·연도별 기록을 보존합니다. 새 저장을 이전 게임에 넣는 역방향 호환은 지원하지 않습니다. 내보내는 파일에 온라인 인증 정보는 포함하지 않습니다.

## 시각과 파일

초기 Dream Loop 3회 이후 사용자 피드백에 따라 화이트·블루·네이비로 개편했습니다. kickru.com의 여백과 명확한 행동 구성을 참고했으며 이미지·화면 코드는 독자적으로 만들었습니다. 내장 이미지 생성 도구로 새로 만든 선수 일러스트 24종을 선택·프로필·전당·PNG 카드에 사용합니다. 기존 아바타 ID 0~23과 저장은 유지합니다. 생성 프롬프트와 원본 아틀라스는 `assets/AVATAR_V3_ART.md`, `assets/rookie-portraits-v3.png`에 있습니다. 실제 선수 사진이나 구단 로고를 참고 이미지로 사용하지 않았습니다. 마지막 두 아바타는 사용자가 요청한 백금발 여성 TS 말포이풍 디자인입니다. 이전 v2 원본도 보존합니다.

배포 `index.html`에는 실행 코드·스타일·선수 아틀라스가 모두 포함됩니다. 핵심 플레이는 HTML로 실행하며 사복·모델 원화 144장은 별도 파일입니다. 설치한 앱은 앱 셸과 이미 불러온 최근 원화 최대 12장을 캐시합니다. 아직 불러오지 않은 원화와 온라인 랭킹은 네트워크가 필요합니다. HTML을 직접 옮길 때는 사복 이미지 폴더도 함께 옮기세요. 이전 더그아웃 원본과 게임 목록용 야구장 이미지는 보존합니다. 원본 1단계 HTML과 개발·검수 이미지는 로컬에서 별도로 보존합니다.

선수 선택 전환, 시즌의 공·베이스·월별 하이라이트, 능력치 막대와 결과 등장에 모션을 적용했습니다. `prefers-reduced-motion`에서는 모션을 끕니다. 모바일 생성은 5열 아바타와 단계 전환 스크롤을 사용합니다. v4에서는 결과·비시즌·선수 화면을 탭으로 나누고, 필수 치료는 하단 기본 행동으로 연결합니다. 해외 자격·부상·소집 제안은 탭 알림으로 표시합니다.

## 2단계 검수본

- 연봉 직접 입력, FA 승인·결렬과 타 구단 3개 제안, 시즌당 트레이드 요청 1회와 항명, KBO 4시즌 이후 MLB·NPB 포스팅. 연봉·역할·계약 기간·이적료와 추정 시장가치를 표시합니다. 계약은 다음 시즌에 반영하며, 이적료는 원소속 구단에 귀속됩니다. 다년 계약 연봉은 트레이드 후에도 보장합니다.
- FA는 KBO 1·2군 등록 시즌을 합산합니다. 고졸 8·대졸 7시즌, 첫 FA 뒤 4시즌으로 간소화했습니다. 재활 공백·병역 시즌은 등록에 포함하지 않습니다.
- 투수·타자 부상, 투구수/출장·신체 능력·관리 방식·내구성을 반영한 위험도, 토미존 수술 1시즌 공백 또는 무리한 복귀, 재활 이벤트 4개. 무리한 복귀는 내구성 상한도 낮추며 장비·재활 상품으로 상한을 넘겨 회복할 수 없습니다.
- 비시즌 상품 3개 고정 입고, 1개 구매, 8개 상품과 가격별 효과, 구매·지출 이력. 효과는 다음 출전 시즌에 적용하며 재활 중에는 대기합니다.
- 청소년 대표·WBC·프리미어12·올림픽·아시안게임의 발탁과 합류 선택, 별도 대회 성적·명성·메달 특례. 실제 개최 일정·선발·병역 규정과 무관한 게임 규칙입니다.
- 상무는 19~27세·OVR 57 이상·최근 성적 조건을 충족한 프로 선수가 지원하며 2시즌 퓨처스 경기를 이어갑니다. 현역은 2시즌 출전·성장 정지, 복귀 시 주요 능력 -2·멘탈 -1입니다. 원소속과 계약을 보관하고 복무 중 프로 연봉 지급과 계약 소진을 멈춘 뒤 복귀 후 남은 계약을 이어갑니다. 치료·재활·이적·소집과의 중복 진입을 차단합니다.
- 홈/반응/시즌/선수/기록 하단 탭, 가상 매체 4개와 댓글 5~6개, 은퇴북의 잠재력 등급·성장 특성·능력치별 성장 상한 공개. 모바일 기록표는 카드 안에서만 가로로 스크롤됩니다.
- 성장 리포트의 증감을 표시된 정수 능력치 차이로 통일했습니다. 은퇴북의 닮은 선수 이름·유사도는 하나의 영역에서 한 번 표시합니다.
- 온라인 전당은 은퇴 시 공개 닉네임으로 선택 등록합니다. 기존 전당과 같은 투표율 순위이며 전체/타자/투수/투타겸업 상위 100개를 조회합니다. 브라우저별 포지션 최고 기록 1개, 본인만 갱신·삭제, 1분 갱신 간격, 서버의 형식·성적 범위·점수 계산 검사와 동시 쓰기 충돌 보호를 적용했습니다. 로컬 저장 파일 조작을 판별하지는 않는 자율 랭킹입니다. 상세는 `server/README.md`를 참고하세요.

병역은 사용자가 승인한 추천 방식으로 구현했습니다. Pages 게임 파일과 Firebase 랭킹 전용 경로 `benchHallV2`가 배포 대상입니다. 다른 운영 규칙·데이터는 그대로 보존합니다.

기존 수학 학습·교사 운영실·학생 제출·친구방 데이터와 로그인 상태를 연결하지 않습니다. 온라인 랭킹 등록 시 별도 앱 이름의 익명 인증만 사용합니다.

## 이전 배포 기록 · 마지막 유니폼 전신 피날레

이전 `066ae6f` 배포에서는 은퇴북 첫 장에 유니폼 전신 기념 일러스트를 사용했습니다. v4는 위 사복 엔딩으로 교체하고 아래 원본을 보존합니다. 24명 모두 타자(배트)·투수(공과 글러브)·투타겸업(배트와 글러브) 3개 포즈를 지원합니다. 최종 출전 구단·포지션·커리어 기간·최고 OVR·통산 기록·우승·개인상·전당 투표율을 함께 표시하며 전당 입성 시 금빛 명패를 사용합니다. 프로 기록이 없으면 아마추어 통산을 보여 줍니다.

은퇴북 5페이지와 기존 얼굴 커리어 카드를 유지하고, 첫 장에 1080 × 1600 전신 포스터 PNG 저장·공유를 더했습니다. 외형은 선택한 아바타를 잇는 기념 원화이고 소속·나이·기록은 해당 커리어의 최종 결과를 표시합니다. 원본 3개 아틀라스, 웹용 WebP와 정확한 생성 프롬프트는 `assets/finale/`에 보존합니다. 웹용 이미지 약 1.05 MB가 HTML에 내장되며 엔딩에서 해당 포지션만 디코딩합니다.

저장 필드·키·커리어 난수·온라인 payload는 바꾸지 않았습니다. 전신 표시·72개 원화 영역·순수 계산·v1/v3 호환 등 443개 검사를 통과했고, 브라우저에서 3포지션/전당 엔딩·모바일 가로 넘침 없음·실제 PNG 저장을 확인했습니다. 기기의 네이티브 공유 시트는 미확인입니다. 이 추가본은 2026-10-24 사용자 승인으로 운영 반영하는 범위입니다.

## 추가 검수본 · 투타겸업 / 새 아바타 / 앱 아이콘

- 생성에서 세 번째 경로 **투타겸업**을 고릅니다. 타격·투구 각 6능력치, 각 합계 240의 후보 3종입니다. 집중 육성은 12개를 합쳐 최대 2개, 겨울 훈련은 한 방향 또는 균형/휴식을 고릅니다. OVR은 타격·투구 OVR 평균입니다.
- 한 시즌에 타격과 투구를 모두 기록합니다. 두 역할의 출전·성장 부담을 분배하고 연봉·팀 우승·국제대회는 중복 지급/집계하지 않습니다. 투구 재활은 한 시즌 투구 출전·성장만 멈추고 타격은 이어갑니다. 현역 복무는 둘 다 멈춥니다.
- 투구 이벤트는 투구 능력치에 반영합니다. 장비·캠프는 두 역할의 효과를 표시하며 재활 중 투구 효과만 복귀까지 기다립니다. 공통 내구성·캠프 명성은 한 번만 적용합니다.
- 타자 기본 후보에 김도영의 장타·주루형, 다른 후보 보기에 이치로의 정교·준족형을 추가했습니다. 은퇴 매칭은 전성기 능력치와 프로 기록을 참고하며 투타겸업은 오타니형으로 표시합니다. 실제 선수의 등급·성적 예측이 아닌 가상 게임 유형입니다.
- 온라인 전당은 `twoWay` 분류를 추가합니다. 기존 타자·투수는 schema 2, 투타는 schema 3 요약입니다. 서버 부분 규칙도 같은 릴리스에 적용합니다. Database/Auth Emulator 검사와 운영 배포 검증은 구분해 기록합니다.
- 홈 화면 앱 아이콘, favicon, Apple touch icon, `manifest.webmanifest`, `sw.js`를 제공합니다. 저장 메뉴에서 설치 안내/지원 브라우저의 설치 버튼을 찾을 수 있습니다. SW는 `/games/bench-to-hall/` 앱 셸만 저장하고 외부 Firebase·학교·허브 페이지는 캐시하지 않습니다. 새 버전은 저장 후 사용자가 적용하며 자동 강제 새로고침은 하지 않습니다.
- 로컬 브라우저에서 실제 앱 셸 캐시 뒤 검수 서버를 중단하고 재접속하는 오프라인 실행을 확인했습니다. iOS/Android 실기기 설치는 미확인입니다.
