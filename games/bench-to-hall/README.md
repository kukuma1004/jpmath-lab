# 벤치에서 전당까지 · JP Math Lab

고교 벤치 선수로 시작하는 한국어 야구 커리어 시뮬레이션의 첫 플레이 버전입니다.

- 게임: https://kukuma1004.github.io/jpmath-lab/games/bench-to-hall/
- 게임 목록: https://kukuma1004.github.io/jpmath-lab/games/

## 플레이와 저장

캐릭터 생성 → 시즌 보내기 → 결과 확인 → 비시즌 선택을 반복합니다. 투수·타자, 24종 아바타, 고교·대학·KBO·NPB·MLB 기본 경로, 성장 이벤트 28개, 5페이지 은퇴 요약과 PNG 카드, 로컬 명예의 전당을 지원합니다.

계정·광고·서버 저장은 없습니다. 선수 기록은 기기와 브라우저에 저장됩니다. 다른 주소·브라우저·기기로 옮길 때 설정에서 JSON을 내보내고 가져오세요. `JP Math Lab · 게임으로`를 누르면 저장을 확인한 뒤 게임 목록으로 돌아갑니다.

## 시각과 파일

Dream Loop에서 현재 화면 → 생성한 목표 이미지 → 구현·브라우저 비교 3회를 진행했습니다. 더그아웃·야구장 장면은 내장 이미지 생성 도구로 새로 만들었고, 선택 가능한 선수는 자체 SVG 픽셀 아트입니다. 생성한 그림에 실제 선수 사진이나 구단 로고는 사용하지 않았습니다.

배포 `index.html`에는 실행 코드·스타일·야구장 이미지가 모두 포함됩니다. 별도 이미지 파일은 게임 목록 카드에도 사용합니다. 원본 1단계 HTML과 개발·검수 이미지는 로컬에서 별도로 보존합니다.
