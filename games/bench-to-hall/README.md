# 벤치에서 전당까지 · JP Math Lab

고교 벤치 선수로 시작하는 한국어 야구 커리어 시뮬레이션입니다. 이적·계약, 부상·재활, 상점, 국가대표·병역, 모바일 탭과 온라인 명예의 전당을 지원합니다. 화이트 UI와 2단계 시스템은 운영 배포를 마쳤습니다. 아래 투타겸업·새 아바타·웹앱 아이콘은 추가 검수본이며 새 운영 승인을 기다립니다.

- 게임: https://kukuma1004.github.io/jpmath-lab/games/bench-to-hall/
- 게임 목록: https://kukuma1004.github.io/jpmath-lab/games/

## 플레이와 저장

캐릭터 생성 → 시즌 보내기 → 결과 확인 → 비시즌 선택을 반복합니다. 투수·타자·투타겸업, 24종 아바타, 고교·대학·KBO·NPB·MLB 기본 경로, 성장 이벤트 31개, 5페이지 은퇴 요약과 PNG 카드, 로컬 명예의 전당을 지원합니다.

회원가입과 광고는 없습니다. 전체 선수 기록은 기기와 브라우저에 저장하며 온라인 등록을 선택한 요약만 서버에 공개합니다. 다른 주소·브라우저·기기로 옮길 때 설정에서 JSON을 내보내고 가져오세요. `JP Math Lab · 게임으로`를 누르면 저장을 확인한 뒤 게임 목록으로 돌아갑니다. 기존 v1/v2 파일과 진행 중인 시즌·비시즌·전당은 같은 로컬 저장 키로 읽습니다. 투타겸업 선수·생성 단계·전당이 포함된 저장만 v3로 내보내고 단일 포지션은 v2를 유지합니다. 새 저장을 이전 게임에 넣는 역방향 호환은 지원하지 않습니다. 내보내는 파일에 온라인 인증 정보는 포함하지 않습니다.

## 시각과 파일

초기 Dream Loop 3회 이후 사용자 피드백에 따라 화이트·블루·네이비로 개편했습니다. kickru.com의 여백과 명확한 행동 구성을 참고했으며 이미지·화면 코드는 독자적으로 만들었습니다. 내장 이미지 생성 도구로 새로 만든 선수 일러스트 24종을 선택·프로필·전당·PNG 카드에 사용합니다. 기존 아바타 ID 0~23과 저장은 유지합니다. 생성 프롬프트와 원본 아틀라스는 `assets/AVATAR_V3_ART.md`, `assets/rookie-portraits-v3.png`에 있습니다. 실제 선수 사진이나 구단 로고를 참고 이미지로 사용하지 않았습니다. 마지막 두 아바타는 사용자가 요청한 백금발 여성 TS 말포이풍 디자인입니다. 이전 v2 원본도 보존합니다.

배포 `index.html`에는 실행 코드·스타일·선수 아틀라스가 모두 포함됩니다. 한 파일로 오프라인 플레이할 수 있으며 온라인 랭킹만 네트워크가 필요합니다. 이전 더그아웃 원본과 게임 목록용 야구장 이미지는 보존합니다. 원본 1단계 HTML과 개발·검수 이미지는 로컬에서 별도로 보존합니다.

선수 선택 전환, 시즌의 공·베이스·월별 하이라이트, 능력치 막대와 결과 등장에 모션을 적용했습니다. `prefers-reduced-motion`에서는 모션을 끕니다. 모바일 생성은 5열 아바타와 단계 전환 스크롤을 사용합니다. 비시즌 필수 이벤트·치료를 먼저 보여주고 계약·건강·상점·국가대표·병역을 접기 메뉴로 탐색합니다. FA 자격이나 소집 제안은 해당 메뉴를 기본으로 펼칩니다.

## 2단계 검수본

- 연봉 직접 입력, FA 승인·결렬과 타 구단 3개 제안, 시즌당 트레이드 요청 1회와 항명, KBO 4시즌 이후 MLB·NPB 포스팅. 연봉·역할·계약 기간·이적료와 추정 시장가치를 표시합니다. 계약은 다음 시즌에 반영하며, 이적료는 원소속 구단에 귀속됩니다. 다년 계약 연봉은 트레이드 후에도 보장합니다.
- FA는 KBO 1·2군 등록 시즌을 합산합니다. 고졸 8·대졸 7시즌, 첫 FA 뒤 4시즌으로 간소화했습니다. 재활 공백·병역 시즌은 등록에 포함하지 않습니다.
- 투수·타자 부상, 투구수/출장·신체 능력·관리 방식·내구성을 반영한 위험도, 토미존 수술 1시즌 공백 또는 무리한 복귀, 재활 이벤트 4개. 무리한 복귀는 내구성 상한도 낮추며 장비·재활 상품으로 상한을 넘겨 회복할 수 없습니다.
- 비시즌 상품 3개 고정 입고, 1개 구매, 8개 상품과 가격별 효과, 구매·지출 이력. 효과는 다음 출전 시즌에 적용하며 재활 중에는 대기합니다.
- 청소년 대표·WBC·프리미어12·올림픽·아시안게임의 발탁과 합류 선택, 별도 대회 성적·명성·메달 특례. 실제 개최 일정·선발·병역 규정과 무관한 게임 규칙입니다.
- 상무는 19~27세·OVR 57 이상·최근 성적 조건을 충족한 프로 선수가 지원하며 2시즌 퓨처스 경기를 이어갑니다. 현역은 2시즌 출전·성장 정지, 복귀 시 주요 능력 -2·멘탈 -1입니다. 원소속과 계약을 보관하고 복무 중 프로 연봉 지급과 계약 소진을 멈춘 뒤 복귀 후 남은 계약을 이어갑니다. 치료·재활·이적·소집과의 중복 진입을 차단합니다.
- 홈/반응/시즌/선수/기록 하단 탭, 가상 매체 4개와 댓글 5~6개, 은퇴북의 잠재력 등급·성장 특성·능력치별 성장 상한 공개. 모바일 기록표는 카드 안에서만 가로로 스크롤됩니다.
- 성장 리포트의 증감을 표시된 정수 능력치 차이로 통일했습니다. 은퇴북의 닮은 선수 이름·유사도는 하나의 영역에서 한 번 표시합니다.
- 온라인 전당은 은퇴 시 공개 닉네임으로 선택 등록합니다. 기존 전당과 같은 투표율 순위이며 전체/타자/투수/투타겸업 상위 100개를 조회합니다. 브라우저별 포지션 최고 기록 1개, 본인만 갱신·삭제, 1분 갱신 간격, 서버의 형식·성적 범위·점수 계산 검사와 동시 쓰기 충돌 보호를 적용했습니다. 로컬 저장 파일 조작을 판별하지는 않는 자율 랭킹입니다. 상세는 `server/README.md`를 참고하세요.

병역은 사용자가 승인한 추천 방식으로 구현했습니다. Pages 게임 파일과 Firebase 랭킹 전용 경로 `benchHallV2`가 배포 대상입니다. 다른 운영 규칙·데이터는 그대로 보존합니다.

기존 수학 학습·교사 운영실·학생 제출·친구방 데이터와 로그인 상태를 연결하지 않습니다. 온라인 랭킹 등록 시 별도 앱 이름의 익명 인증만 사용합니다.

## 마지막 유니폼 · 전신 피날레

은퇴북 첫 장에 선택한 아바타의 전신 기념 일러스트가 나옵니다. 24명 모두 타자(배트)·투수(공과 글러브)·투타겸업(배트와 글러브) 3개 포즈를 지원합니다. 최종 출전 구단·포지션·커리어 기간·최고 OVR·통산 기록·우승·개인상·전당 투표율을 함께 표시하며 전당 입성 시 금빛 명패를 사용합니다. 프로 기록이 없으면 아마추어 통산을 보여 줍니다.

은퇴북 5페이지와 기존 얼굴 커리어 카드를 유지하고, 첫 장에 1080 × 1600 전신 포스터 PNG 저장·공유를 더했습니다. 외형은 선택한 아바타를 잇는 기념 원화이고 소속·나이·기록은 해당 커리어의 최종 결과를 표시합니다. 원본 3개 아틀라스, 웹용 WebP와 정확한 생성 프롬프트는 `assets/finale/`에 보존합니다. 웹용 이미지 약 1.05 MB가 HTML에 내장되며 엔딩에서 해당 포지션만 디코딩합니다.

저장 필드·키·커리어 난수·온라인 payload는 바꾸지 않았습니다. 전신 표시·72개 원화 영역·순수 계산·v1/v3 호환 등 443개 검사를 통과했고, 브라우저에서 3포지션/전당 엔딩·모바일 가로 넘침 없음·실제 PNG 저장을 확인했습니다. 기기의 네이티브 공유 시트는 미확인입니다. 이 추가본도 운영 승인 전 로컬 검수 상태입니다.

## 추가 검수본 · 투타겸업 / 새 아바타 / 앱 아이콘

- 생성에서 세 번째 경로 **투타겸업**을 고릅니다. 타격·투구 각 6능력치, 각 합계 240의 후보 3종입니다. 집중 육성은 12개를 합쳐 최대 2개, 겨울 훈련은 한 방향 또는 균형/휴식을 고릅니다. OVR은 타격·투구 OVR 평균입니다.
- 한 시즌에 타격과 투구를 모두 기록합니다. 두 역할의 출전·성장 부담을 분배하고 연봉·팀 우승·국제대회는 중복 지급/집계하지 않습니다. 투구 재활은 한 시즌 투구 출전·성장만 멈추고 타격은 이어갑니다. 현역 복무는 둘 다 멈춥니다.
- 투구 이벤트는 투구 능력치에 반영합니다. 장비·캠프는 두 역할의 효과를 표시하며 재활 중 투구 효과만 복귀까지 기다립니다. 공통 내구성·캠프 명성은 한 번만 적용합니다.
- 타자 기본 후보에 김도영의 장타·주루형, 다른 후보 보기에 이치로의 정교·준족형을 추가했습니다. 은퇴 매칭은 전성기 능력치와 프로 기록을 참고하며 투타겸업은 오타니형으로 표시합니다. 실제 선수의 등급·성적 예측이 아닌 가상 게임 유형입니다.
- 온라인 전당은 `twoWay` 분류를 추가합니다. 기존 타자·투수는 schema 2, 투타는 schema 3 요약입니다. 서버 부분 규칙도 같은 릴리스에 적용해야 하며 운영 반영 전까지는 로컬 Emulator에서만 확인했습니다.
- 홈 화면 앱 아이콘, favicon, Apple touch icon, `manifest.webmanifest`, `sw.js`를 제공합니다. 저장 메뉴에서 설치 안내/지원 브라우저의 설치 버튼을 찾을 수 있습니다. SW는 `/games/bench-to-hall/` 앱 셸만 저장하고 외부 Firebase·학교·허브 페이지는 캐시하지 않습니다. 새 버전은 저장 후 사용자가 적용하며 자동 강제 새로고침은 하지 않습니다.
- 로컬 브라우저에서 실제 앱 셸 캐시 뒤 검수 서버를 중단하고 재접속하는 오프라인 실행을 확인했습니다. iOS/Android 실기기 설치는 미확인입니다.

검수: 투타 900시즌/10,608개 검사, 기존 엔진과 단일 포지션 200시즌 동일성, 기존 3,000시즌·v1 이전 및 계약/건강/상점/병역 검사, 투타 추가 상점·대표팀·저장 129개 검사, 기존 온라인 42개 + 신규 투타 온라인 27개 Emulator 검사. 모바일 390px 생성→시즌→결과→훈련, JSON/PNG 다운로드, 은퇴북·투타 순위 등록/삭제를 화면에서 확인했습니다.
