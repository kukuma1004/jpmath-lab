# 벤치에서 전당까지 · JP Math Lab

고교 벤치 선수로 시작하는 한국어 야구 커리어 시뮬레이션입니다. 2단계 검수본에는 이적·계약, 부상·재활, 상점, 국가대표·병역, 모바일 탭과 온라인 명예의 전당이 구현되어 있습니다. 운영 반영 승인 전이므로 아래 공개 주소는 아직 기존 버전입니다. 온라인 등록·조회는 로컬 테스트 서버에서 검증했습니다.

- 게임: https://kukuma1004.github.io/jpmath-lab/games/bench-to-hall/
- 게임 목록: https://kukuma1004.github.io/jpmath-lab/games/

## 플레이와 저장

캐릭터 생성 → 시즌 보내기 → 결과 확인 → 비시즌 선택을 반복합니다. 투수·타자, 24종 아바타, 고교·대학·KBO·NPB·MLB 기본 경로, 성장 이벤트 28개, 5페이지 은퇴 요약과 PNG 카드, 로컬 명예의 전당을 지원합니다.

회원가입과 광고는 없습니다. 전체 선수 기록은 기기와 브라우저에 저장하며 온라인 등록을 선택한 요약만 서버에 공개합니다. 다른 주소·브라우저·기기로 옮길 때 설정에서 JSON을 내보내고 가져오세요. `JP Math Lab · 게임으로`를 누르면 저장을 확인한 뒤 게임 목록으로 돌아갑니다. 기존 v1 파일과 진행 중인 시즌·비시즌·전당을 같은 로컬 저장 키에서 v2로 이전합니다. v2 파일을 옛 v1 게임으로 가져오는 역방향 호환은 지원하지 않습니다. 내보내는 파일에 온라인 인증 정보는 포함하지 않습니다.

## 시각과 파일

Dream Loop에서 현재 화면 → 생성한 목표 이미지 → 구현·브라우저 비교 3회를 진행했습니다. 더그아웃·야구장 장면은 내장 이미지 생성 도구로 새로 만들었고, 선택 가능한 선수는 자체 SVG 픽셀 아트입니다. 생성한 그림에 실제 선수 사진이나 구단 로고는 사용하지 않았습니다.

배포 `index.html`에는 실행 코드·스타일·야구장 이미지가 모두 포함됩니다. 별도 이미지 파일은 게임 목록 카드에도 사용합니다. 원본 1단계 HTML과 개발·검수 이미지는 로컬에서 별도로 보존합니다.

## 2단계 검수본

- 연봉 직접 입력, FA 승인·결렬과 타 구단 3개 제안, 시즌당 트레이드 요청 1회와 항명, KBO 4시즌 이후 MLB·NPB 포스팅. 연봉·역할·계약 기간·이적료와 추정 시장가치를 표시합니다. 계약은 다음 시즌에 반영하며, 이적료는 원소속 구단에 귀속됩니다. 다년 계약 연봉은 트레이드 후에도 보장합니다.
- FA는 KBO 1·2군 등록 시즌을 합산합니다. 고졸 8·대졸 7시즌, 첫 FA 뒤 4시즌으로 간소화했습니다. 재활 공백·병역 시즌은 등록에 포함하지 않습니다.
- 투수·타자 부상, 투구수/출장·신체 능력·관리 방식·내구성을 반영한 위험도, 토미존 수술 1시즌 공백 또는 무리한 복귀, 재활 이벤트 4개. 무리한 복귀는 내구성 상한도 낮추며 장비·재활 상품으로 상한을 넘겨 회복할 수 없습니다.
- 비시즌 상품 3개 고정 입고, 1개 구매, 8개 상품과 가격별 효과, 구매·지출 이력. 효과는 다음 출전 시즌에 적용하며 재활 중에는 대기합니다.
- 청소년 대표·WBC·프리미어12·올림픽·아시안게임의 발탁과 합류 선택, 별도 대회 성적·명성·메달 특례. 실제 개최 일정·선발·병역 규정과 무관한 게임 규칙입니다.
- 상무는 19~27세·OVR 57 이상·최근 성적 조건을 충족한 프로 선수가 지원하며 2시즌 퓨처스 경기를 이어갑니다. 현역은 2시즌 출전·성장 정지, 복귀 시 주요 능력 -2·멘탈 -1입니다. 원소속과 계약을 보관하고 복무 중 프로 연봉 지급과 계약 소진을 멈춘 뒤 복귀 후 남은 계약을 이어갑니다. 치료·재활·이적·소집과의 중복 진입을 차단합니다.
- 홈/반응/시즌/선수/기록 하단 탭, 가상 매체 4개와 댓글 5~6개, 은퇴북의 잠재력 등급·성장 특성·능력치별 성장 상한 공개. 모바일 기록표는 카드 안에서만 가로로 스크롤됩니다.
- 성장 리포트의 증감을 표시된 정수 능력치 차이로 통일했습니다. 은퇴북의 닮은 선수 이름·유사도는 하나의 영역에서 한 번 표시합니다.
- 온라인 전당은 은퇴 시 공개 닉네임으로 선택 등록합니다. 기존 전당과 같은 투표율 순위이며 전체/타자/투수 상위 100개를 조회합니다. 브라우저별 포지션 최고 기록 1개, 본인만 갱신·삭제, 1분 갱신 간격, 서버의 형식·성적 범위·점수 계산 검사와 동시 쓰기 충돌 보호를 적용했습니다. 로컬 저장 파일 조작을 판별하지는 않는 자율 랭킹입니다. 상세는 `server/README.md`를 참고하세요.

병역은 사용자가 승인한 추천 방식으로 구현했습니다. 최종 검수본을 확인한 뒤 게임 파일의 Pages 업데이트와 Firebase의 랭킹 전용 규칙 활성화를 승인받아 운영에 반영합니다. 다른 운영 규칙·데이터는 그대로 보존합니다.

기존 수학 학습·교사 운영실·학생 제출·친구방 데이터와 로그인 상태를 연결하지 않습니다. 온라인 랭킹 등록 시 별도 앱 이름의 익명 인증만 사용합니다.
