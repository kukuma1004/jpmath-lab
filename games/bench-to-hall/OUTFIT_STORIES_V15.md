# R15 비시즌 의상과 구단 이야기

사용자 요청에 따라 성인 캐릭터의 여름·스포츠·행사 의상과 일상 장면을 늘립니다. 노출 수위를 구매 금액이나 호감도에 연동하지 않습니다. 2026-11-07 사용자의 “배포해” 승인에 따라 이 변경을 공개 배포 대상으로 확정했습니다. 공개 반영은 해당 커밋의 Pages 완료·파일 해시·실제 공개 브라우저 검사로 검증합니다.

- 여성 아바타 13명에게 얼굴별 6장면, 총 78장면을 추가합니다. 꽃시장 오프숄더 원피스, 민소매 러닝복, 스포츠 원피스 수영복, 홀터넥 블라우스와 린넨 팬츠, 정원 디너 드레스, 테니스복입니다. 여성 얼굴당 추억 종류가 18종에서 24종으로 늘고 남성의 기존 6종은 유지합니다.
- 모든 상품의 기존 65% 장식용 랜덤 해금과 미수집 장면 우선 선택을 유지합니다. 가격·구매 제한·효과·커리어 난수·경기 결과·온라인 순위 계산은 그대로입니다. 예전 구매 기록에 새 장면을 소급 생성하지 않습니다. 21세 미만·복무 중은 훈련 이야기, 부상·재활 중은 기존 라운지 휴식만 표시합니다.
- KBO 10개 구단의 성인 가상 응원단 30명에게 각각 두 장면, 총 60장면을 추가합니다. 호감도 70에서는 여름 나들이 화보, 90에서는 공연·행사·스포츠를 주제로 한 기념 화보를 남깁니다. 얼굴·구단 색·각 인물의 머리 모양을 기존 원화에서 유지합니다. 일반적인 사복과 공연·행사 의상의 차이이며 노출의 단계 상승이 아닙니다.
- 기존 만남 횟수·취향별 호감도 증가량·나들이 비용·같은 인물 시즌 1회/전체 시즌 2회 제한을 유지합니다. 해당 조건을 채운 후 좋아하는 활동으로 새로 만난 날에만 `clubLife.history[].look`을 선택 필드로 추가합니다. 이전 기록은 필드를 추가하거나 이미지를 교체하지 않습니다. 이전 저장은 그대로 읽고, 새 필드는 내보내기/가져오기에서 유지하고 조건을 검증합니다.
- 인물별 화면과 라운지 추억 목록에서 해금한 의상별 기록을 다시 볼 수 있습니다. 다시 열거나 새로고침해도 재추첨·추가 비용·능력 보상이 없습니다.
- 원화는 Built-in `image_gen`의 `identity-preserve`로 미리 생성합니다. 여성 선수 참조는 30세 성인 은퇴 원화, 응원단 참조는 기존 25~29세 가상 성인 원화입니다. 실제 인물 사진을 사용하지 않습니다. 각각 1536×1024의 3열×2행 아틀라스이며 원본 구도를 바꾸지 않고 WebP로 인코딩합니다. 게임 중 유료 이미지 API 호출은 없습니다.
