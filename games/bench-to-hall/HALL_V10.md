# R10 명예의 전당 심사

입성선은 75%입니다. 새 은퇴에서는 1군 유효 경력 10시즌과 뛰어난 시즌 5회도 모두 필요합니다. 한두 해의 폭발이나 장기근속·수상 횟수만으로 입성하지 않도록 바꿨습니다.

| 항목 | 최대 | 기준 |
|---|---:|---|
| 통산 실적 | 40 | 타자의 안타·홈런·도루, 투수의 승·탈삼진·이닝·세이브·홀드 |
| 전성기 | 28 | 가장 좋은 7시즌의 성적·출전 기회·OVR·리그 수준 |
| 지속성 | 12 | 뛰어난 시즌의 누적 |
| 개인상 | 18 | 1군 MVP·사이영상·홈런왕·골든글러브·신인왕, 같은 해 같은 상은 한 번 |
| 우승 기여 | 2 | 실제 1군 출전 연도의 해당 리그 우승 |

유효 경력은 타자 200타석, 투수 30이닝 이상인 시즌입니다. 선발은 150이닝, 불펜은 50이닝을 기준으로 전성기 출전 기회를 평가합니다. 타자는 OPS 또는 타율·도루, 투수는 ERA·탈삼진율을 활용합니다. 투타겸업은 두 역할의 기여를 합치되 항목 상한을 공유합니다. 고교·대학·2군·복무·공백은 제외합니다. 국적·자금·명성은 평가 보너스를 주지 않습니다. 실제 WAR나 공식 리그 전당 규정이 아닌 게임 평가식입니다.

새 은퇴는 `player.hallAssessment`에 평가를 확정합니다. 기존 v1~v5 저장의 확정 은퇴/전당 투표율은 이전 평가로 보존하며, 진행 중 커리어가 앞으로 은퇴할 때 새 심사를 받습니다. 시즌 기록·RNG·자금·이미지는 재계산하지 않습니다. 미입성 커리어도 은퇴 기록 보관함과 저장 파일에 남습니다. 온라인 커리어 점수·최고 연봉·이전 전당 순위의 계산과 서버 규칙은 변경하지 않습니다.

가상 표본 180커리어(기본 진행 90·투자 진행 90)를 같은 완성 기록으로 비교한 결과, 기존 심사는 54명, 새 심사는 11명이 입성했습니다. 이는 특정 전략·잠재력 범위로 만든 검수 표본이며 전체 사용자 입성 확률을 뜻하지 않습니다. 타자·선발·마무리·중간계투·투타겸업의 뛰어난 기록은 입성하고 평균적인 장기근속은 탈락하는 경계를 확인했습니다.

검증: 평가·과거 투표·온라인 점수 보존·실제 시즌 계산 동일성 187개, 격리 Chrome의 입성/미입성·5페이지 평가·재접속·기존 은퇴 보존 25개. v1~v5 보관함 85개, 저장 11개, 순위 동기화/개인정보 14개를 통과했습니다. 대표팀·모바일 변경도 실제 화면의 42개 패널/234개 접근성 검사와 선택·저장 18개를 통과했습니다. 운영 데이터에 테스트 기록을 쓰지 않았으며 실제 휴대전화는 검사하지 않았습니다.
