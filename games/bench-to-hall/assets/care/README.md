# 비시즌 특별 장면 · 기본 6종 + 여성 확장 12종

여성 아바타 `1,3,5,6,9,11,14,16,17,19,21,22,23`에만 신규12종을 추가했습니다. 여성은 얼굴별18종, 남성은 기존6종으로 전체 케어 원화는300장면입니다. 기존 기본 원화24개와 이전 구매 기록은 보존하며, 앞으로 구매한 장면만 해금합니다. 확장 파일은 `avatar-{id}-moments-extra-a-v1.webp` 및 `avatar-{id}-moments-extra-b-v1.webp` 26개입니다. 각각1536×1024, 3열×2행의512×512 장면6개입니다. 현재 장면의 얼굴과 묶음만 필요할 때 불러옵니다.

| 묶음 | 왼쪽 위부터 행 순서 |
| --- | --- |
| extra-a | 라군 수영 / 서핑 / 밤 온천 / 풀사이드 독서 / 테라스 조식 / 요가 |
| extra-b | 세일링 / 야간 수영장 / 스파 휴식 / 스킨케어 / 디너 / 카바나 |

확장 원화도 Built-in `image_gen`의 `identity-preserve`로 제작했습니다. 해당 얼굴의 **성인** 은퇴 스포츠 모델 원화만 참조하고 모든 인물을30세 성인 여성으로 지정했습니다. 수영복, 래시가드, 운동복, 닫힌 가운, 여름 원피스, 드레스와 사복으로 의상을 나눴습니다. PNG 원본은 이미지 라이브러리와 로컬 `.dream-loop/female-care/masters/`에 보존하며 WebP는 크기·구도 수정 없이 인코딩했습니다.

## 기존 기본 6종

24개의 선택 얼굴 × 6개 케어·훈련 장면을 미리 생성한 아틀라스입니다. 게임 중 이미지 API를 호출하지 않습니다. 기본 장면과 여성 확장을 경제·구단 라운지 릴리스에 포함합니다. 검수·배포 범위는 게임README에서 확인합니다.

각 `avatar-{0..23}-moments-v1.webp`는 1536×1024, 정확히 3열×2행입니다. 왼쪽 위부터 온천, 수영장, 해변 훈련, 어깨 케어, 가운 라운지, 리조트 사복입니다. 한 장면은 512×512입니다. 게임에서는 선택한 영역 하나를 CSS로 보여줍니다. 한 선수의 파일 약 0.3MB만 해당 장면이나 앨범을 열 때 내려받으며, 사용하지 않은 23명의 원화를 한꺼번에 받지 않습니다.

Built-in `image_gen`의 `identity-preserve` 방식으로 제작했습니다. 얼굴 참조는 해당 아바타의 기존 **성인 은퇴 스포츠 모델 원화** `../afterlife/avatar-{id}-active-v1.webp`입니다. 생성 인물은 28세 이상 성인이며, 실제 선수 사진·미성년 프로필·추가 인물 사진을 참조하지 않았습니다. 불투명한 스포츠 수영복·래시가드·트레이닝복·닫힌 가운·사복을 사용합니다. 원본 PNG는 이미지 라이브러리와 로컬 `.dream-loop/care-scenes/masters/`에 보존합니다. WebP는 원본 크기와 구도를 유지한 배포용 인코딩입니다.

## 게임 연결

개인 트레이너, 재활 프로그램, 영양사, 멘탈 코치, 수비 클리닉, 퍼포먼스 랩, 해외훈련에 상품과 연결되는 장면이 있습니다. 장비 구매는 장면을 해금하지 않습니다. 신규 구매 한 번에 한 장면만 결정하며 같은 상품군에서 아직 만나지 않은 장면을 우선합니다. 커리어 난수와 분리된 해시로 결정하므로 다시 열기·새로고침·선수 전환으로 재추첨되지 않습니다.

21세 미만 또는 복무 중인 선수는 유니폼 프로필을 곁들인 팀 회복 이야기만 표시합니다. 부상·수술 재활 중인 성인은 운동·물놀이 대신 라운지 휴식으로 표시합니다. 저장한 구매 당시 나이는 구매 시즌+15와 일치해야 하고 현재 나이와도 대조합니다. 미성년 시절 기록은 성인이 된 뒤에도 성인 목욕·수영복 장면으로 바뀌지 않습니다.

구매 성공 후 `shop.purchases[].moment={schema:1,scene,age,avatar}`만 추가합니다. 기존 가격·구매 제한·성장 효과·잠재력·명성·경기 결과·커리어 RNG·랭킹 payload를 유지합니다. 이전 구매에는 장면을 소급해서 만들지 않습니다. v1~v5 저장에서 새 필드는 선택 사항이며 보관함·전당·전체/개별 파일 내보내기에 함께 보존합니다. 원화나 인증 정보는 저장 JSON에 넣지 않습니다.

상점, 선수→추억, 설정, 은퇴북에서 앨범을 열 수 있습니다. 이미 만난 장면만 표시하고 같은 장면은 최근 추억을 보여줍니다. 전체 연도별 추억은 상점 구매 이력에서도 다시 열 수 있습니다. 자동 표시를 꺼도 해금은 저장됩니다. 설정은 브라우저의 별도 키에 저장합니다. 재생으로 추가 보상을 얻을 수 없습니다.

서비스 워커는 기존 은퇴 원화와 이번 아틀라스를 합쳐 최근 12개만 캐시합니다. 아직 받지 않은 이미지에는 연결이 필요하며 실패하면 프로필과 다시 열기 안내를 보여 줍니다. 이미지 실패가 구매나 시즌 진행을 막지는 않습니다.
