# R12 모바일 입력·시즌 화면 보완

2026-10-30 R12에서 검수한 모바일 수정 내용입니다. 사용자 승인에 따라 R13 상점 수정과 함께 배포합니다. 공개 반영은 Pages·파일·브라우저로 별도 확인합니다.

- 연봉 입력의 실제 글자 크기는 14px였습니다. 1023px 이하 화면에서 연봉을 포함한 텍스트 입력·선택 항목을 16px로 통일했습니다. iOS 입력 자동 확대를 유발하는 작은 글자를 보완하며, 사용자의 수동 확대는 계속 허용합니다. 키보드가 열리며 화면 높이가 줄어도 입력 중인 칸이 내부 스크롤 영역에서 보이도록 맞춥니다. [관련 개발사 수정 사례](https://gitlab.com/gitlab-org/gitlab/-/merge_requests/220666).
- 기존 시즌 화면은 구장 높이를 고정 여백으로 계산해, 390×667 화면에 하단 안전 여백 34px를 적용하면 건너뛰기 버튼이 탭 아래로 가려졌습니다. 이제 실제 하단 탭의 위쪽 위치와 보이는 화면 높이를 기준으로 시즌 카드 공간을 정합니다. 진행률·월·44px 이상 버튼 공간을 확보한 뒤 남는 공간에 왼쪽 구장을 맞춥니다. 오른쪽 긴 중계 문장은 내부에서 스크롤할 수 있습니다.
- 화면 크기·브라우저 도구 모음·하단 안전 여백이 달라지면 다시 맞춥니다. 하단 탭의 패딩 변경도 감지하도록 테두리 영역을 관찰합니다. 1024px 이상 데스크톱은 기존 배치를 유지합니다.
- 저장 형식·시즌 기록·계약·게임 엔진은 변경하지 않았습니다. 진행 중 새로고침과 결과로 건너뛰기를 확인했습니다. 다음 배포 시 새 앱 캐시 버전으로 전환합니다.

격리된 Chrome 모바일 환경에서 320×480부터 1023×768까지 12개 크기 × 하단 여백 0/34px, 총 24개 조합을 확인했습니다. 모바일 검수 156개, 수정 전/후·데스크톱 비교 4개, 기존 연봉/표시 테스트 7개를 통과했습니다. 키보드가 열린 상황은 높이를 줄여 모사했고, 실제 iPhone Safari 기기에서는 검수하지 않았습니다. 운영 저장·온라인 순위에 테스트 기록을 쓰지 않았습니다. 검수 자료는 로컬 `.dream-loop/mobile-v12/`에 있습니다.
