# R13 상점 비교·뜻밖의 추억

2026-10-30 사용자 승인 범위입니다. R12의 연봉 입력·시즌 버튼 수정과 함께 배포하며 공개 반영은 별도 검증합니다.

- 상품을 하나씩 넘기던 방식을 없앴습니다. 추천 순서로 전체 상품을 표시하고, 모바일은 2열·데스크톱은 3열로 가격과 효과를 비교합니다. 종류별 필터와 효과 확인·구매 확정은 유지합니다. 긴 설명의 전체 내용은 구매 확인 창에서 읽을 수 있습니다.
- 특정 상품의 '특별 장면 포함' 표시와 상품별 장면 연결을 없앴습니다. 모든 상품에서 구매 확정 후 별도의 장식용 난수로 추억 발생과 장면을 정합니다. 상품 효과·가격·구매 한도·성장 확률은 바꾸지 않습니다. 발생 확률은 코드의 `DATA.careSurprise.chance`에 분리했으며 화면에서는 어떤 상품에 어떤 장면이 나올지 예고하지 않습니다.
- 이미 본 장면보다 아직 보지 않은 장면을 우선 선택합니다. 선수 얼굴에 맞는 기존 원화를 사용하며, 새 원화를 만들지는 않았습니다. 21세 미만·복무 중에는 일상 훈련 이야기, 부상·재활 중에는 휴식 장면으로 제한합니다.
- 기존 schema 1 추억은 그대로 읽습니다. 새 schema 2 추억도 같은 네 필드로 저장하며 앨범 열기·새로고침·내보내기·가져오기에서 다시 추첨하지 않습니다. 특별 장면 자동 표시 설정도 유지합니다.
- 키보드에 맞춘 위치 조정은 텍스트 입력에만 적용해, 상점 상품 버튼을 누를 때 화면이 움직이지 않도록 했습니다.

로컬 검수: 표시·계약·상점 회귀 테스트 12개, 세 역할 × 상품 12종의 구매/효과/다음 시즌 비교와 이전 저장 점검 162개, 상점 브라우저 검수 35개를 통과했습니다. 상점은 320~1280px 여섯 너비에서 확인했으며 세 상품의 비용 정산·이미지·앨범·새로고침을 검증했습니다. 장면을 고정한 테스트 난수는 격리 검수 브라우저에서만 주입했고 배포 코드에는 넣지 않았습니다. 운영 선수·온라인 순위에 검수 기록을 쓰지 않았습니다. 검수 자료는 로컬 `.dream-loop/shop-v13/`에 있습니다.
