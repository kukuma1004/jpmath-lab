# 천뢰 성장·마당 공략 개편 검증

2026-11-22 구현, 2026-11-23 공개 반영 검증. 기존 다섯 전사·여덟 수호신·원화·랭킹 저장 경로와 서버 규칙을 유지한다.

## 변경 결과

- 같은 출현표를 좌우로 뒤집어 반복하던 구간을 없애고, 함포 접근·교차 광선·화로탑 파괴·별비 통로·눈보라 장벽·재조준 원혼탄 등 여덟 공략을 구성했다. 파괴 가능한 발사원은 표식과 체력으로 구분하고, 격파하면 연결된 탄과 활성 광선도 사라진다.
- 수호신을 쓰러뜨리면 이번 출격의 각성이 1→8단으로 오른다. 동행 무기가 0→4기로 늘고, 4단부터 전사별 비전과 차지가 진화한다. 피격으로 사격 단계를 잃어도 각성은 유지한다. 재출격은 1단, 수련은 선택 마당에 맞는 각성으로 시작한다.
- HUD에 각성 단계·실제 기본 공격 배율·동행 수·차지 이름을 표시하고, 클리어 화면에서 해금한 무공을 보여 준다. 작은 가로 화면에서 HUD·공략 안내·터치 조작이 겹치지 않도록 정리했다.
- 원화 로딩 전에 첫 마당이 그려지면 이후 원화가 적용되지 않던 경합과, 클리어 애니메이션이 화면 가운데 정렬을 덮어쓰던 문제도 수정했다.

## 검증과 재현

저장소 루트에서 실행한다.

```powershell
npm run build:publish --prefix games/cheonroe/source
node --test tests/cheonroe-growth.test.mjs tests/cheonroe-ranking-model.test.mjs
python -m http.server 5202 --bind 127.0.0.1
# 별도 터미널
node tests/cheonroe-growth-browser.test.mjs
```

- TypeScript·Vite 공개 빌드 통과. 일반 URL에서는 QA 훅을 제공하지 않으며, `?qa=1`은 공개 기록 등록과 로컬 랭킹 기록을 비활성화한다.
- 엔진·랭킹 검사 23개 통과. 실제 보스 격파와 다음 마당 승계, 피격·일시정지·재출격, 다섯 전사의 비전·차지 효과, 전 구간 경고·안전 통로·탄 수 상한, 장기 최대 각성 및 효과 메타데이터 정리를 검사했다.
- Edge 공개용 정적 빌드 브라우저 검사 39개 통과. 다섯 전사 각각 각성 1/4/8단, 여덟 마당, 클리어 보상과 실제 키보드 이동·차지·일시정지·재개·재출격, 844×390 모바일 에뮬레이션의 터치 이동·회피를 확인했다. 실행·콘솔·리소스 오류 0개.
- 기존 스크린샷 검사 방식을 확장한 자동 캡처를 사용했다. 현재 캡처와 결과는 `.dream-loop/cheonroe-growth/browser/`에 생성된다. 차지→발사→접촉의 멈추지 않은 세 프레임과 실제 화면을 열어 육안 검수했다.
- 캔버스 검사기 원본의 `inspectPage`를 설치된 Edge와 가로 모바일 뷰포트에서 호출했다. 데스크톱 플레이·보스, 모바일 플레이 세 상태 모두 실제 하드웨어 GPU, 비어 있지 않은 화면, 오류 0 및 기본 렌더 예산 통과. 보고서는 `.dream-loop/cheonroe-growth/canvas/`에 있다. 캡처 해상도와 정지된 장면의 프레임 시간은 실제 휴대폰 성능 증거가 아니다.
- 오디오 확인은 사용자 클릭으로 AudioContext 실행, 일시정지·재개·메뉴·재출격의 활성 상태, 음소거·해제 및 신규 이벤트의 런타임 오류 확인에 한정한다. 실제 스피커 청음은 하지 않았다.

## 공개 반영

검증한 변경만 커밋하고 최신 `origin/main`의 다른 게임 변경 위에 반영한 뒤 `git push origin HEAD:main`으로 GitHub Pages에 배포한다. 해당 SHA의 Pages 작업 성공, 공개 HTML·JS·CSS의 해시 일치, 공개 사이트 브라우저 동작과 랭킹 읽기를 별도로 확인한다. 그 결과와 SHA는 `.dream-loop/cheonroe-growth/release.json`에 기록한다.

이번 개편은 서버 규칙이나 기존 공개 기록을 쓰거나 삭제하지 않는다. 원화 추가 없이 기존 WebP와 공용 Three.js 번들을 사용하며, 공개 앱 JS는 약 165KB(압축 57KB), CSS는 약 30KB(압축 8KB)다. 물리 휴대폰·실제 계정 점수 제출·사람의 여덟 마당 완주는 이번 검증 범위에 포함하지 않는다.

## 2026-11-23 자동 근접 방어 수정

사용자 제보: 적에게 붙으면 자동 근접 공격이 탄을 계속 없애 위험을 무시할 수 있다. 확인 결과 근접마다 반경 105의 탄을 금화로 바꾸는 처리가 0.16~0.32초마다 반복됐다.

자동 근접의 탄 소거만 제거했다. 근접 추가 피해·공격 간격·사거리·근접 격파 점수 ×1.5는 유지한다. 별개 기술인 차지·각성 비전, 회피·필살기와 적 격파 보상은 유지하며, 도움말도 탄을 막지 않는다는 설명으로 고쳤다.

- `node --test tests/cheonroe-melee.test.mjs tests/cheonroe-growth.test.mjs tests/cheonroe-ranking-model.test.mjs`: 32개 통과. 새 근접 회귀 9개는 다섯 전사·두 난이도·각성 1/8단의 피해/탄 통과, 금화 생성 방지, 격파 보상, 몸체 접촉·광선, 회피·필살기 방어를 포함한다.
- 고정 적 옆에서 조준탄을 맞는 2초 재현: 수정 전 20개 조합 모두 피격 0, 수정 후 모두 피격 1. 두 경우 모두 근접 공격이 계속 발동했다. 실제 엔진의 피격 후 무적 시간은 유지하며, 이 수치는 해당 고정 조건의 결과다. 원본: `.dream-loop/cheonroe-melee/{before-camping-metrics,camping-metrics}.json`.
- `node tests/cheonroe-melee-browser.test.mjs`: 실제 첫 수호신의 패턴을 근접 추적하는 합성 봇을 데스크톱 린 1단·가로 모바일 철귀 8단에서 실행했다. 두 경우 모두 근접 연타 중 5회 피격하고 게임오버가 됐다. 회피·차지·필살기·탄 주입을 사용하지 않았다. 사람의 난도나 실기기 성능을 입증하는 검사는 아니다.
- `node tests/cheonroe-growth-browser.test.mjs`: 새 공개용 정적 빌드에서 기존 성장·전환·조작·모바일 검사 39개 재통과. 실행·콘솔·리소스 오류 0.
- TypeScript·Vite 빌드 및 `git diff --check` 통과. QA 훅은 계속 `?qa=1`에서만 동작하며 공개 기록을 쓰지 않는다. 이번 수정의 공개 SHA·Pages 작업·파일 해시·공개 보스 압박 검사는 `.dream-loop/cheonroe-melee/release.json` 및 `public-browser/results.json`에 기록한다.
