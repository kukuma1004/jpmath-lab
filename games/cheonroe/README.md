# 천뢰: 철화전선 (v4, 각성과 마당 공략)

JP Math Lab의 오리지널 횡스크롤 탄막 슈팅입니다. 한국 전설과 전통 건축을 배경으로 여덟 마당을 지나며, 마당마다 다른 배경·적·중간 보스와 수호신 보스가 나옵니다. 느린 탄막 사이를 요리조리 피하는 재미가 중심입니다.

| 마당 | 이름 | 수호신 |
| --- | --- | --- |
| 첫째 | 붉은 달의 계곡(산사·홍살문·장승) | 도깨비 장군 |
| 둘째 | 구름바다 하늘길 | 철갑 거북선 |
| 셋째 | 달빛 대숲 | 구미호 |
| 넷째 | 불꽃 제련성(화성 성곽·대장간) | 불가사리 |
| 다섯째 | 별밤 서라벌(첨성대) | 삼족오 |
| 여섯째 | 백설 산사 | 빙룡 |
| 일곱째 | 저승길(삼도천) | 저승차사 |
| 마지막 | 천뢰궁(구름 위 궁궐) | 뇌공(사물놀이 북) |

전사는 다섯 명입니다. 랭킹 id는 괄호 안의 값으로 고정됩니다.

| 전사 | 무기 | 필살 |
| --- | --- | --- |
| 무녀 린(`rin`) | 부채탄, 집중하면 한 줄로 모임 | 홍련만개 |
| 철귀(`golem`) | 관통 광선, 유도 미사일 | 천공멸살포 |
| 무진(`ryu`) | 파동탄, 가장 긴 근접 연타 | 패왕뇌격 |
| 궁수 하늬(`hanui`) | 관통 화살, 차지하면 화살비 | 천궁 화살비 |
| 처녀귀신 아랑(`arang`) | 쫓아가는 도깨비불, 차지하면 머리카락 휘감기 | 한의 곡성 |

- 공개 경로: `/jpmath-lab/games/cheonroe/`
- 화면 전체를 쓰는 게임입니다. 출격하면 전체 화면을 요청합니다(아이폰 사파리는 화면 채우기만). 전장 높이는 720이고, 화면 비율에 맞춰 가로 폭이 1040~1520 사이로 바뀝니다.
- 속도: 세상 시계(`TEMPO` 0.66)가 탄·적·보스 패턴을 느리게 돌리고, 전사의 이동과 사격은 실제 시간으로 움직입니다. 일반 구간은 94~110 세상 초입니다. 초반 편대를 뒤집어 반복하던 후반부를 없애고 마당별 공략을 만들었습니다. 보스의 체력은 각성에 맞춰 다시 올리지 않으므로 성장할수록 더 빨리 쓰러뜨릴 수 있습니다.
- 조작:
  - 방향키/WASD 이동, Shift 집중, C/K 회피 돌진(2회 저장, 2.2초마다 회복, 잠깐 무적).
  - Z 차지, X/Space 필살, P/Esc 정지, F 전체 화면.
  - 사격과 근접 공격은 자동입니다. 적에게 바짝 붙으면 근접 공격이 나가고, 휘두른 자리의 적 탄은 금화가 됩니다.
  - 모바일은 화면 아무 곳이나 드래그하면 상대 이동하고, 회피·차지·필살·집중 단추를 씁니다.
- 판정: 전사 가슴의 흰 점(반지름 4)만 맞습니다. 적 탄은 흰 심의 가장자리가, 레이저는 흰 띠 폭이 판정입니다. 적·보스 판정은 그림 위의 원 여러 개로 정합니다(`types.ts`의 `ENEMIES.hit`). `?qa=1&hitbox=1`로 판정 원을 화면에 그려 볼 수 있습니다.
- 아케이드는 첫째 마당부터 끝까지 합니다(목숨 3). 수련은 원하는 마당부터 할 수 있습니다(목숨 5, 느린 탄).

## 각성과 공략

각성은 이번 출격 안에서 유지되는 성장입니다. 수호신 격파마다 1단씩 올라 최대 8단이 되며, 피격해도 내려가지 않습니다. 사격 아이템의 1~4단 강화와는 별개입니다. 새 출격은 각성 1단부터 시작하고, 수련은 선택한 마당의 단계로 시작합니다. 보유 점수나 이전 공개 기록은 바꾸지 않습니다.

- 각성 2단부터 전사마다 모양과 공격이 다른 동행 무기가 합류합니다. 4·6·8단에 2·3·4기로 늘어납니다.
- 4단에 린의 추적 홍련, 철귀의 폭쇄 관통창, 무진의 광역 충격파, 하늬의 머리 위 화살비, 아랑의 탄을 지우는 혼령이 열립니다. 이후 주기와 범위가 강화됩니다.
- 차지는 더 빨리 모이고, 4단부터 추적 꽃잎·폭발 관통·넓은 충격파·화살비 증가·동행 원혼이 추가됩니다. 공격력 배율은 8단에서 2.12배이며, 동행과 비전의 추가 피해는 별도입니다.
- HUD에 각성 단계·공격 배율·동행 수가 나오고, 마당 돌파 때 새로 열린 무공을 보여 줍니다.

| 마당 | 일반 구간의 공략 |
| --- | --- |
| 붉은 달의 계곡 | 표식 적 격파, 근접·차지로 길 만들기 |
| 구름바다 하늘길 | 함포 예고와 휴지기 사이로 접근해 함선 격침 |
| 달빛 대숲 | 교차 광선 사이 중앙 길을 읽고 발사원 격파 |
| 불꽃 제련성 | 위아래 화로탑을 파괴해 회전 광선 끊기 |
| 별밤 서라벌 | 머리 위 별비가 남긴 이동 통로 따라가기 |
| 백설 산사 | 교대 장벽의 틈과 해빙 통로 이용 |
| 저승길 | 멈췄다 재조준하는 탄의 주인부터 격파 |
| 천뢰궁 | 앞 마당에서 익힌 함포·별비·광선·장벽의 연계 돌파 |

파괴할 수 있는 발사원은 표식과 체력 막대로 표시합니다. 해당 적이 쓰러지면 연결된 탄과 광선이 사라집니다. 각 공략은 시작 전 예고와 안내를 제공하며, 광선 경고는 적어도 1.25 세상 초 유지합니다.

## 소스와 빌드

개발 원본은 `source/`에 있고, 실제 공개 파일은 이 폴더의 `index.html`과 `assets/`입니다. 게임은 `source/public/assets/`의 WebP만 읽습니다.

그림 원본은 무게 때문에 저장소에 넣지 않았습니다. 만든 PC의 `Documents/Claude/2026-11-20/cheonroe-art`에 있습니다.
- `raw2/`: ChatGPT 프로젝트 "이미지 생성(천뢰 게임)"의 배경·보스·전사 채팅에서 받은 원본입니다.
- `process2.py`: 초록 배경을 지우고 WebP로 바꾸며, 보스 판정 원을 계산합니다.
- v1 PNG는 `source/art/`에 있습니다.

- `src/stages.ts`: 여덟 마당의 보스 공격 패턴. `src/encounters.ts`: 반복 없는 일반 구간 공략과 적 출현표. `src/progression.ts`: 각성·동행·비전의 수치와 배치.
- `src/engine.ts`: 순수 시뮬레이션. `src/renderer.ts`: Three.js 화면. `src/main.ts`: 화면과 조작.
- `node scripts/bot.mjs [rin|golem|ryu|hanui|arang|all] [normal|story] [--react=0.25]`: 반응이 늦은 회피 봇이 여덟 마당을 플레이합니다. 마당별 보스 시간, 피격 수, 구간 평균 탄 수, 어느 패턴에서 맞았는지를 보여 줍니다.

```powershell
cd games/cheonroe/source
npm ci
npm test
npm run build:publish
```

## 공개 랭킹

메뉴와 결과 화면에서 랭킹을 열 수 있습니다.
- 수련/아케이드와 다섯 전사를 따로 집계하고, 전체 전사 상위 100개도 조회합니다. 같은 점수는 공동 순위입니다.
- 10초 이상 플레이한 뒤 끝난 판을 사용자가 직접 등록합니다. 닉네임은 한글·영문·숫자·공백·`_ . -`, 최대 12자입니다.
- 여덟 마당 완주는 한 시간을 넘을 수 있습니다. 그래서 기록하는 플레이 시간은 서버 상한인 60분에서 멈춥니다.
- 전체 전사 목록을 읽을 때, 한 전사 목록을 읽지 못해도 나머지는 보여 줍니다.

각 브라우저는 난이도·전사마다 최고 기록 1개만 제출하며, 더 낮은 점수로 기존 기록을 덮지 않습니다. 갱신은 10초 간격이고, 본인 공개 기록은 삭제할 수 있습니다. 내 기록과 설정은 브라우저에 저장되며, 공개 기록을 지워도 로컬 점수는 지워지지 않습니다.

랭킹의 익명 인증 앱과 데이터베이스 경로는 학생·교사와 다른 게임에서 분리되어 있습니다. 서버 규칙은 소유권·허용 필드·형식·숫자 범위·정렬 조회·갱신 간격을 검증합니다. 게임 플레이 자체를 서버에서 재현하지는 않는 자율 랭킹입니다. `?qa=1` 검수 모드에서는 공개 기록 등록과 로컬 랭킹 기록이 꺼집니다.
