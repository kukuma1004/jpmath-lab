# 천뢰: 철화전선 (v2)

JP Math Lab의 오리지널 횡스크롤 탄막 슈팅. 다섯 개의 장(붉은 달의 계곡 · 구름바다 하늘길 · 불꽃 제련성 · 백설 산사 · 천뢰궁)마다 다른 배경·적·중간 보스와 3~4단계 수호신 보스가 나옵니다. 피하는 재미가 중심입니다.

- 공개 경로: `/jpmath-lab/games/cheonroe/`
- 화면 전체를 쓰는 게임입니다. 출격하면 전체 화면을 요청하고(아이폰 사파리는 화면 채우기만), 화면 비율에 맞춰 전장 가로 폭이 1300~1900 사이로 바뀝니다.
- 조작: 방향키/WASD 이동, Shift 집중(느리게·스침 범위 표시), C/K 회피 돌진(2회 저장·1.5초마다 회복·잠깐 무적), Z 차지, X/Space 필살, P/Esc 정지, F 전체 화면. 사격과 근접 공격은 자동입니다. 모바일은 화면 아무 곳이나 드래그(상대 이동)와 회피·차지·필살·집중 버튼.
- 판정: 전사 가슴의 흰 점(반지름 4)만 맞습니다. 적 탄은 흰 심의 가장자리가 곧 판정이고, 레이저는 흰 띠 폭이 판정입니다. 적·보스 판정은 그림 위의 원 여러 개로 정의합니다(`types.ts`의 `ENEMIES.hit`). `?qa=1&hitbox=1`로 판정 원을 화면에 그려 확인할 수 있습니다.
- 완벽 회피: 회피 무적 중에 탄을 아슬아슬하게 넘기면 시간이 느려지고, 주변 탄이 금화로 바뀌며 회피가 바로 1회 돌아옵니다.
- 필살 게이지: 스침·완벽 회피·격파·피격으로 차고, 100마다 1회(최대 3회). 쓰면 화면의 탄이 모두 금화가 됩니다. 린은 꽃잎 폭풍, 철귀는 앞쪽을 가르는 거대 광선, 무진은 적마다 내리꽂는 낙뢰.
- 아케이드는 1장부터 끝까지(목숨 3), 수련은 원하는 장부터(목숨 5, 느린 탄).

## 소스와 빌드

개발 원본은 `source/`, 실제 공개 파일은 이 폴더의 `index.html`과 `assets/`입니다. 게임은 `source/public/assets/`의 WebP만 읽습니다(원화 합계 약 21MB → 1.5MB). v1 원본 PNG 9장은 `source/art/`에 있고, v2에서 ChatGPT로 만든 원본 12장(초록 배경 지우기 전·후)은 무게 때문에 저장소에 넣지 않았습니다(만든 PC의 `Documents/Claude/2026-11-20/cheonroe-art`).

- `src/stages.ts` 다섯 장의 적 출현표와 보스 공격 패턴, `src/engine.ts` 순수 시뮬레이션, `src/renderer.ts` Three.js 화면(장마다 코드로 그리는 원경·중경·근경 + GPT 배경), `src/main.ts` 화면·조작.
- 그림이 없는 적·보스·배경은 기존 원화에 색을 입혀 대신 쓰고, 배경은 코드로 그린 층만 보여 줍니다.
- `node scripts/bot.mjs [rin|golem|ryu|all] [normal|story] [--god]` 회피 봇이 다섯 장을 플레이해 장별 시간·보스 시간·피격 수를 보여 줍니다(패턴에 피할 틈이 있는지 확인용).

```powershell
cd games/cheonroe/source
npm ci
npm test
npm run build:publish
```

## 공개 랭킹

메뉴와 결과 화면에서 랭킹을 열 수 있습니다. 수련/아케이드와 세 전사를 따로 집계하고 전체 전사 상위 100개도 조회합니다. 같은 점수는 공동 순위입니다. 10초 이상 플레이한 뒤 끝난 판의 닉네임·전사·점수를 사용자가 직접 등록합니다. 닉네임은 한글·영문·숫자·공백·`_ . -`, 최대 12자입니다.

각 브라우저는 난이도·전사마다 최고 기록 1개를 제출하며, 더 낮은 점수로 기존 기록을 덮지 않습니다. 갱신은 10초 간격이고 본인 공개 기록을 삭제할 수 있습니다. 내 기록·설정은 브라우저 저장이며, 공개 기록 삭제가 로컬 점수를 지우지는 않습니다.

랭킹의 익명 인증 앱과 데이터베이스 경로는 학생·교사 및 다른 게임과 분리합니다. 서버 규칙은 소유권·허용 필드·형식·숫자 범위·정렬 조회·갱신 간격을 검증합니다. 전체 게임 플레이 자체를 서버에서 재현하지 않는 자율 랭킹입니다. `?qa=1` 검수 모드는 공개 기록 등록과 로컬 랭킹 기록을 비활성화합니다.
