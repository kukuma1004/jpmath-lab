# 천뢰: 철화전선

JP Math Lab의 오리지널 횡스크롤 탄막 슈팅. 린·철귀·무진의 기본 사격, 차지, 근접 공격과 고유 궁극기, 첫 스테이지의 3단계 기계 수호신 보스를 플레이합니다.

- 공개 경로: `/jpmath-lab/games/cheonroe/`
- 게임 목록: `/jpmath-lab/games/`
- 방향키/WASD 이동, Shift 정밀 이동, Z 홀드 후 차지 해방, X/Space 궁극기, P/Esc 정지. 기본 사격과 근접 공격은 자동입니다. 모바일은 전장 드래그와 별도 공격 버튼을 사용하며 가로 화면을 권장합니다.
- 원화 9장과 완성된 첫 스테이지를 포함합니다. 여러 스테이지·협동 플레이·관절별 프레임 애니메이션은 이 버전에 포함하지 않습니다.

## 소스와 빌드

개발 원본은 `source/`, 실제 공개 파일은 이 폴더의 `index.html`과 `assets/`입니다. 생성 원본 PNG는 `source/public/assets/`에 보존합니다. 기존 다른 게임의 파일을 빌드에 사용하지 않습니다.

```powershell
cd games/cheonroe/source
npm ci
npm test
npm run build:publish
```

소스의 `npm run dev`는 로컬 Vite를 사용합니다. 사이트 통합 확인은 저장소 루트에서 정적 HTTP 서버를 켜고 `/games/cheonroe/`로 진입하세요. `build:publish`는 자신의 이전 HTML이 참조한 낡은 JS/CSS 해시만 정리하며 원화·소스·저장을 보존합니다.

## 공개 랭킹

메뉴와 결과 화면에서 랭킹을 열 수 있습니다. 수련/아케이드와 세 전사를 따로 집계하고 전체 전사 상위 100개도 조회합니다. 같은 점수는 공동 순위입니다. 10초 이상 플레이한 뒤 끝난 판의 닉네임·전사·점수를 사용자가 직접 등록합니다. 닉네임은 한글·영문·숫자·공백·`_ . -`, 최대 12자입니다.

각 브라우저는 난이도·전사마다 최고 기록 1개를 제출하며, 더 낮은 점수로 기존 기록을 덮지 않습니다. 갱신은 10초 간격이고 본인 공개 기록을 삭제할 수 있습니다. 내 기록·설정은 브라우저 저장이며, 공개 기록 삭제가 로컬 점수를 지우지는 않습니다.

랭킹의 익명 인증 앱과 데이터베이스 경로는 학생·교사 및 다른 게임과 분리합니다. 서버 규칙은 소유권·허용 필드·형식·숫자 범위·정렬 조회·갱신 간격을 검증합니다. 전체 게임 플레이 자체를 서버에서 재현하지 않는 자율 랭킹입니다. `?qa=1` 검수 모드는 공개 기록 등록과 로컬 랭킹 기록을 비활성화합니다.

## 서버

부분 규칙과 안전한 병합 배포 도구는 `server/`에 있습니다. 전체 운영 규칙을 이 부분 파일로 덮어쓰지 않습니다. 자세한 배포·검증 범위는 [server/README.md](server/README.md)를 참고하세요. 실 기기 검증과 별도의 운영 브라우저 검증은 구분해 보고합니다.
