# 해협 돌파 · 여덟 전선

휴대폰에서는 화면을 좌우로 끌고, PC에서는 방향키나 마우스 드래그로 움직입니다. 사격은 자동입니다.

- 청록색 증원문을 통과해 병력을 모으세요. `+8`은 8명 추가, `×2`는 현재 병력의 두 배를 뜻합니다. 최대 병력은 36명입니다.
- 금색 무기 상자를 쏴 남은 숫자를 0으로 만들면 석궁이 삼연발, 관통 화살, 폭발 화살로 바뀝니다. 4챕터부터는 강화가 덜 된 플레이어에게 후반 보급 상자가 한 번 더 나옵니다.
- 바닥에 공격 범위를 표시하는 띠가 나타나면 빈 곳으로 이동하세요. 보스마다 공격 방향과 순서가 다릅니다.
- 보스를 격파하면 다음 챕터가 열립니다. 같은 브라우저에서 같은 주소로 열면 이전 돌파 기록으로 이어서 플레이할 수 있습니다.

성문 전선 → 빙벽 협곡 → 잿불 제련소 → 침엽수 고개 → 폭풍 방파제 → 황혼 수로 → 붉은 채석장 → 검은 성채

단일 HTML은 WebGL 2 지원 브라우저에서 열 수 있습니다. 앱 설치나 인터넷 연결 없이 PC에서 플레이할 수 있습니다.

```sh
npm ci
npm run dev
npm run build
node artifacts/routes.mjs
node artifacts/release-check.mjs
```

출력 파일은 `dist/index.html`입니다. Edge에서 8챕터를 마우스로 검증하려면 `node artifacts/playtest.mjs`를 실행하세요. 동작 검증 시간을 단축하려면 개발 검증에만 쓰는 `BREAKWATER_TEST_RATE` 값을 설정할 수 있습니다.
