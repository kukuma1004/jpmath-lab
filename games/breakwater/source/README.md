# 해협 돌파 · 성문 전선

돌다리 위에서 석궁병을 이끌어 몰려오는 적을 막고 철문 수문장을 쓰러뜨리는 모바일 3D 게임입니다.

- 휴대폰에서는 좌우로 끌어 움직입니다. PC에서는 방향키 또는 마우스 드래그를 사용합니다. 사격은 자동입니다.
- 왼쪽의 `+6`, `×2` 증원문을 통과하면 아군 대열이 늘어납니다. 한 명으로 출발해 최대 36명까지 모을 수 있습니다.
- 오른쪽 무기 상자를 쏴 숫자를 0으로 만들면 삼연발, 관통 화살, 폭발 화살을 순서대로 얻습니다.
- 보스가 바닥에 공격 범위를 표시하면 띠 바깥으로 이동하세요.
- 0.3.1에서는 2공세부터 기습대가 좌우에서 번갈아 접근합니다. 철문 수문장의 체력이 절반 아래로 떨어지면 더 자주 넓은 범위를 공격합니다.

제공된 단일 HTML은 WebGL 2를 지원하는 브라우저에서 열 수 있습니다. PC에서는 오프라인으로도 플레이할 수 있습니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5192
npm run build
```

빌드 파일은 `dist/index.html`입니다. 빌드 후 `node artifacts/playtest.mjs`로 입력과 전투를 검수할 수 있습니다.
