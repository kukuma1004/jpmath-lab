# 해협 돌파

바다 위 방파제를 달리는 구조대를 이끄는 한 판짜리 3D 슈팅 게임입니다.

0.2에서 적의 다음 대열이 더 빨리 이어지고, 공세가 바뀔수록 증원 간격이 짧아집니다. 해안 조명과 포말, 교량 재질, 로봇 장갑과 달리는 모션도 다듬었습니다.

- 휴대폰은 화면을 좌우로 밀고, PC는 드래그하거나 방향키를 누릅니다. 사격은 자동입니다.
- 왼쪽 게이트를 통과하면 동료가 합류합니다. 오른쪽 숫자 표적을 맞혀 숫자를 0으로 만들면 부채꼴과 관통 사격을 얻습니다. 같은 갈림길에서는 두 보상 중 먼저 얻은 한 가지를 받습니다.
- 마지막 보스가 바닥에 붉은 띠를 표시하면 띠 밖으로 움직이세요. 동료를 잃어 인원이 0명이 되면 작전이 종료됩니다.

## 실행

제공된 단일 HTML 파일은 WebGL 2를 사용할 수 있는 브라우저에서 바로 열립니다. 휴대폰으로 플레이할 때는 같은 HTML 파일을 정적 웹 호스팅에 올려 링크를 여는 방법을 사용할 수 있습니다.

## 개발

Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

```sh
npm ci
npm run dev
npm run build
```

빌드 결과는 `dist/index.html`입니다. 3D 모델, 텍스처, 음향을 코드에서 생성하며 빌드 결과를 여는 데 외부 파일이나 네트워크가 필요하지 않습니다.

- `src/combat.js`에 적 배치, 피해, 보상, 탄막 규칙이 있습니다.
- `src/world.js`에 해안과 유닛 모델이 있습니다.
- `src/field-effects.js`에 게이트, 표적, 탄환과 피격 효과가 있습니다.
- `src/main.js`는 화면, 입력, 진행 상태를 연결합니다.

`artifacts`에 두 차례의 드림루프 기록과 브라우저 검수 결과가 있습니다.
