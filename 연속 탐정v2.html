연속은 세 단서가 모두 맞아야 해요

x = a에서 그래프가 이어지는지를 ‘눈대중’이 아니라 세 가지 조건으로 판정합니다.

f(x)가 x = a에서 연속일 조건
① f(a)가 정의된다.
② lim x→a f(x)가 존재한다. (좌극한 = 우극한)
③ lim x→a f(x) = f(a) 이다.

어떤 단서가 깨졌을까요?

헷갈리기 쉬운 점

“점이 찍혀 있으면 연속?”
아니에요. 좌·우에서 향하는 값이 다르면 불연속입니다.
“극한이 존재하면 연속?”
아니에요. f(a)가 없거나 극한값과 다르면 불연속입니다.
“조각함수면 불연속?”
아니에요. 접합점에서 세 조건을 모두 만족하면 연속입니다.
1. 먼저 f(a)실제 찍힌 점이 있는지 확인
2. 좌·우에서 접근둘이 같은 곳으로 향하는지 확인
3. 마지막 대조극한값과 f(a)가 같은지 확인

연속성 현장 조사

사례를 고르고, 세 조건을 직접 확인한 다음 최종 판정을 받아 보세요.

초록 점: 함수값 f(a) · 주황 빈 원: 극한이 향하는 값 · 점선: x = a

세 조건 체크리스트

순서대로 증거를 모아 봅시다.

① f(a)가 정의되나요?
아직 확인하지 않았어요.
② 극한이 존재하나요?
왼쪽과 오른쪽에서 각각 접근해 보세요.
관찰 기록: 접근 버튼을 눌러 보세요.
③ 극한값 = f(a) 인가요?
앞의 두 조건을 확인하면 비교할 수 있어요.
세 조건을 조사하면 결론이 나타납니다.

구멍 수선실

아래 함수는 x = 1에서 구멍이 있지만, f(1)의 값만 고치면 연속으로 수선할 수 있어요.

f(x) = x + 2 (x ≠ 1),   f(1) = 0
함수의 길f(1)의 위치
x = 1에서 그래프가 향하는 높이를 찾아, 초록 점을 그 위치로 옮겨 보세요.

점 하나를 움직여 수선하기

힌트: x가 1에 가까워질 때 그래프가 향하는 높이를 보세요.
극한값lim x→1 f(x) = 3
수선 조건f(1)을 3으로 맞추면 세 조건이 모두 통과합니다.
